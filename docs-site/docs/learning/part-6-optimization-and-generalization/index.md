# 卷六 优化、噪声与泛化

> 本卷属于第二编“机器学习与神经网络”，负责把静态网络结构推进成真实训练过程，并建立优化、统计噪声与泛化之间的关系。

如果说上一卷主要在回答：

> 神经网络内部怎样形成表示，输出端又怎样接到可训练的分布接口上？

那么这一卷开始回答另一组同样关键的问题：

> 误差怎样真正传回参数？训练为什么不可能完全无噪声？模型为什么会在训练集上越来越好，却不一定真的学会可迁移的规律？

这就是为什么这一卷必须从卷五里独立出来。

它处理的不是“再补几个训练术语”，而是神经网络第一次真正进入动态过程之后，会立刻遇到的三类现实：

1. 参数更新必须有方向。
2. 方向估计天然带噪声。
3. 训练目标变好不自动等于泛化能力变好。

## 为什么这一卷不能继续藏在“神经网络基础”里面

很多初学者第一次学深度学习时，最容易被下面这种写法带偏：

- 前向
- loss
- backward
- step

看上去很短，像是一条四行就能背下来的训练口令。

但真正一进入训练现场，你立刻就会碰到一批此前只是“见过”的词：

- 梯度
- 链式法则
- 反向传播
- mini-batch
- gradient noise
- overfitting
- validation

如果这些内容还和“表示、softmax、交叉熵”混在同一卷里，读者很容易陷入一种状态：

> 每个词好像都知道一点，但完全说不清它们为什么必须在同一台机器里相遇。

所以现在主线明确把这一层单独拎出来。

本卷要做的，是把训练动力学讲成一条连续因果链，而不是一组经验口令。

## 这一卷真正处理的是哪三层问题

### 第一层：参数怎样知道往哪里改

这对应梯度、偏导、链式法则与反向传播。

它们不是数学装饰。

它们是在回答一个极其朴素的问题：

> 当模型做错时，内部成千上万个参数究竟怎样知道自己各自应该承担多少责任？

### 第二层：为什么真实训练一定带噪声

这对应 mini-batch、梯度估计、随机顺序与训练曲线波动。

很多初学者会把“训练不平滑”本能地理解成“哪里出 bug 了”。

但真实训练天然就是统计过程。

模型每一步看到的都只是全体数据的一小部分。
因此每一步拿到的更新方向，本来就不是完整真相，而是一个局部估计。

### 第三层：为什么训练变好不自动等于模型真的学会

这对应过拟合、泛化、验证集和模型选择。

如果没有这一层意识，读者后面几乎一定会误判：

- 训练 loss 下降就等于一切都在变好
- 训练更久就等于模型更强
- 指标好看就等于能力稳定

这些判断在语言模型世界里都不成立。

## 为什么语言模型读者更需要这一卷

很多人会以为：

> 这些内容更像通用机器学习背景，等到真正训练语言模型时再看也来得及。

这其实很危险。

因为后面你训练一个小语言模型时，所有最常见的现象都会直接回到这里：

- loss 下降但样例仍然很差
- batch 一变，训练风格就变
- 学习率稍大就爆炸
- 训练集越跑越低，验证集却不再改善

如果本卷没有先稳住，后面这些现象只会显得像“很多工程经验”。

而本卷的目的正是让你明白：

> 它们不是经验碎片，而是同一条训练动力学在不同位置上的表现。

## 本卷的三章分别在做什么

### 第一章：[01. 梯度、链式法则、反向传播与优化](/learning/part-3-machine-learning-and-neural-networks/07-gradients-backpropagation-and-optimization)

这一章先回答训练中最基本也最容易被神秘化的问题：

- 梯度到底是什么
- 链式法则为什么会自然出现
- 反向传播为什么不是魔法，而是计算图上的高效求导
- 优化器到底在利用什么信息推动参数

读完这一章，你应该能够把 `loss.backward()` 还原回一条真正可解释的因果链。

### 第二章：[02. 小批量梯度下降、噪声与训练的统计本性](/learning/part-3-machine-learning-and-neural-networks/08-mini-batch-gradient-descent-noise-and-why-training-is-statistical)

这一章处理训练中的“非理想性”：

- 为什么不可能总用全量数据更新
- 为什么单样本更新又会过于抖动
- mini-batch 究竟在折中什么
- 训练曲线为什么天然会抖
- 为什么噪声不总是坏事

这一章会帮你把“统计训练”从一种模糊印象变成稳定直觉。

### 第三章：[03. 过拟合、泛化与验证集](/learning/part-3-machine-learning-and-neural-networks/09-overfitting-generalization-and-validation)

这一章把训练从“会下降”推进到“会迁移”：

- 什么叫只记住训练集
- 什么叫真正学到可推广规律
- 为什么验证集必须存在
- 为什么模型选择不能只看训练 loss

这里建立起来的判断力，会直接影响你后面怎样看待语言模型训练日志与样例输出。

## 这一卷想留下的不是术语，而是判断力

读完这一卷，最重要的不是记住更多定义。

更重要的是建立下面三种判断力。

### 第一，方向判断力

你会更自然地区分：

- 当前问题是模型不会表示
- 还是损失回传没有真正把方向传到位

### 第二，统计判断力

你会开始接受：

> 训练曲线不是实验室里的理想直线，而是带噪估计驱动下的统计轨迹。

这会直接改变你对 batch、shuffle、step 波动和随机种子的理解。

### 第三，泛化判断力

你会更自然地问：

- 这个下降发生在训练集还是验证集
- 这是能力变强，还是只是把已见样本记得更牢

这类判断，会在后面训练语言模型时反复出现。
