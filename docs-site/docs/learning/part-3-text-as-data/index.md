# Part 3. 文本为什么能变成训练数据

这一分册会把视角从“神经网络如何学习”推进到“语言数据怎样进入神经网络”。

很多初学者会以为文本就是字符串，模型读取文本就是把字符串喂进去。真正动手做之后才会发现，中间隔着一整套必须认真处理的层次：

- 字符编码
- 文本清洗
- token 化
- 词表设计
- special token
- 样本打包
- 目标右移

如果这部分没有系统讲清楚，后面的模型结构即使写对了，也会因为输入定义不稳而训练失败或行为奇怪。

- [02. Unicode、字节与文本规范化](/learning/part-3-text-as-data/02-unicode-bytes-and-text-normalization)
- [03. Token、词表与 special token](/learning/part-3-text-as-data/03-tokens-vocabularies-and-special-tokens)

后续还会继续展开：

## 这一分册为什么会显得比很多人预想中更“基础”

很多人第一次接触 LLM 项目时，会把文本预处理看成工程细节，觉得“真正关键的是模型结构”。

这是一个很危险的误判。

因为模型并不是直接读取自然语言，而是读取：

- 某种编码后的文本
- 某种 token 切分结果
- 某种固定长度样本组织方式

也就是说：

> 数据是怎样进入模型的，会直接决定模型到底在学什么。

如果文本边界、special token、样本右移方式、词表定义这些事情没讲清楚，那么模型后面的所有结构都可能建立在不稳的输入定义上。

## 读完之后你应该达到什么状态

读完这一分册后，你应该能稳定回答：

- 为什么文本不能被当作普通字符串直接输入模型
- 为什么 tokenizer 属于模型定义的一部分
- 为什么 special token 不是装饰
- 为什么数据清洗和规范化会影响最终训练目标

这些能力会直接决定你后面实现 tokenizer、数据集和训练样本时是否容易踩坑。

在阅读顺序上，这一分册应该接在“神经网络基础”之后，因为只有当前面已经理解：

- 表示
- 分布
- 交叉熵

你才更容易真正明白“文本怎样变成一个可训练的分布预测任务”。
