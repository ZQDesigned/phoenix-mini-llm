# 03. 矩阵乘法、线性变换与维度流动

## 为什么神经网络代码里到处都是矩阵乘法

当你开始阅读模型实现时，很快就会发现一个事实：

> 大量核心计算都可以被还原成某种矩阵乘法或线性投影。

例如：

- embedding 查表之后的表示变换
- 线性层
- Q、K、V 投影
- 输出头

如果你只把这些都当成“框架自动完成的标准层”，你会始终停留在组件名称层面。

所以这一章的目标不是让你做繁杂计算，而是先建立最重要的直觉：

> 矩阵乘法在模型里通常是在做特征重组、空间投影和维度变换。

## 先从最简单的点积直觉开始

两个等长向量相乘并求和，会得到一个标量。

这件事常被称为点积。

你可以把它看成：

> 用一组权重规则，去衡量两个向量在多大程度上对齐。

这个直觉后面会反复出现。

例如：

- 线性层里，一个输出维度本质上就是输入向量和一组权重向量的点积
- 注意力打分里，query 和 key 的相似度也会落到点积或其变体

也就是说，很多复杂结构最底层都在问：

> 这两组数按某种规则组合后，结果多大？

## 矩阵乘法可以理解成“很多次点积一起做”

如果一个向量与一个矩阵相乘，你可以把矩阵看成：

- 很多组权重向量按行或按列堆在一起

那么乘法的结果就像是在同时询问：

- 这组输入分别和多组权重匹配后会得到什么新结果

于是一个输入向量可以被变换成另一个维度的输出向量。

这就是线性层最底层的计算语言。

## 线性变换的本质不是“复制”，而是“重组”

很多初学者第一次看全连接层时，会不自觉地把它理解成：

> 输入第一个维度去影响输出第一个维度，第二个影响第二个。

这并不准确。

更准确的理解是：

> 输出空间中的每个维度，通常都是输入各维按不同权重组合出来的新方向。

这意味着线性变换在做三件事：

- 重新组合原始特征
- 改变表示所在的空间
- 必要时改变维度大小

所以它不是简单拷贝，而是在“重新安排你怎样描述这个对象”。

## 为什么“维度变化”本身就有语义

设输入是一个 512 维表示，经过线性层变成 2048 维。

这不是机械放大，而是在说：

> 我们希望把原来较紧凑的表示投到一个更宽的空间里，让后续计算有机会表达更丰富组合。

反过来，如果一个表示从 512 维投回到 512 维，也不意味着“什么都没变”。

即使输入输出维度相同，线性层仍然可能在做非常重要的基变换和特征重排。

所以看维度时不要只问“有没有变大变小”，更要问：

> 这个投影前后，模型希望表示的角色发生了什么变化？

## 语言模型里最常见的线性流动

下面几种维度变化会在语言模型里反复出现。

### `[B, T, H] -> [B, T, H]`

这通常表示：

- 每个位置都被独立地重新投影到同一隐藏空间尺寸中

很多内部投影虽然保持隐藏维不变，但表示已经被重写。

### `[B, T, H] -> [B, T, 3H]` 或拆成多个分支

这类操作常出现在一次性生成多个投影时，例如：

- Q、K、V
- 门控前后不同分支

它意味着同一个输入表示被送往多条功能不同的后续路径。

### `[B, T, H] -> [B, T, V]`

这通常出现在输出头，表示：

- 每个位置的隐藏状态被映射成对整个词表的打分

从“表示空间”走向“类别空间”。

## 为什么矩阵乘法总要配合 shape 一起看

矩阵乘法最容易出错的地方不是概念，而是维度兼容。

你不必先记所有符号规则，但要牢记一件事：

> 一个乘法是否合理，首先要看被相乘的轴是否在语义上真的对应。

例如，当我们把 `[B, T, H]` 的最后一维与某个 `[H, D]` 权重矩阵相乘时，意思是：

- 对每个 batch
- 对每个位置
- 都把那个 `H` 维表示投到一个新的 `D` 维空间

所以真正参与“特征组合”的是最后那一维。

这就是为什么理解“最后一维通常承载当前表示向量”很重要。

## 维度流动是理解模型结构的关键方法

在看一段模型代码时，一个非常有效的阅读方法是：

> 不先纠结实现细节，先跟踪张量形状怎样一步步变化。

例如：

```text
[B, T]
-> [B, T, H]
-> [B, T, H]
-> [B, T, V]
```

只要你能稳定追踪这条流动，你对整台模型已经有了骨架级理解。

之后再去问：

- 这一步为什么需要投影
- 这一步为什么需要拆头
- 这一步为什么要再合并回来

就会容易很多。

## 这和 Attention 有什么关系

后面讲 Attention 时，你会发现 Q、K、V 的生成本身就是线性投影。

也就是说，Attention 并不是“脱离线性层的全新魔法”，而是在已有表示上：

- 先做几次不同用途的线性变换
- 再根据这些变换后的表示决定如何读取信息

所以现在先理解线性变换，后面进入 Attention 才不会显得突兀。

## 这一章结束后最该留下的直觉

你应该带走下面几个判断标准：

- 矩阵乘法通常是在做特征重组，不是机械复制
- 线性层本质上是在不同表示空间之间投影
- 维度变不变，都可能伴随重要语义变化
- 阅读模型时，先看维度流动，再看每一步的具体目的

一旦这个直觉稳定下来，线性层、投影层和输出头都会更容易看懂。
