# 06. 对数、信息量与为什么损失常写成对数概率

## 很多初学者第一次在 loss 里看到 `log` 会感到突兀

到这里为止，你已经知道语言模型在预测概率分布。

接下来通常会看到一些看起来更“数学化”的对象：

- 对数概率
- 负对数似然
- 交叉熵
- 困惑度

如果没有前置直觉，这些名字很容易变成纯背诵。

所以这一章先不急着进入完整公式，而是先回答：

> 为什么语言模型训练里总会反复出现对数？

## 对数先不用怕，把它当成“把乘法变加法”的工具

对数最重要的实用直觉之一是：

> 它能把连乘关系变成求和关系。

这件事在概率里非常有价值。

因为当我们看一个长序列的整体概率时，本质上常常是在把很多条件概率连乘起来。

如果直接乘：

- 数值容易非常小
- 不容易稳定处理
- 不方便分析每一步贡献

一旦取对数，就会更容易：

- 数值更稳定
- 长序列目标能拆成一项项之和
- 每个位置的影响更清楚

## 为什么“概率高”会自然变成“损失低”

训练时，我们希望模型对真实目标给出更高概率。

例如真实下一个 token 是 `x`，那我们希望：

\[
P(x \mid \text{context})
\]

尽量大。

但优化时，我们通常习惯把问题写成“最小化某个损失”。于是一个自然想法就是：

> 如果真实目标概率越大越好，那损失就应该在这个概率变大时下降。

负对数概率正好满足这个直觉：

- 概率越大，`log(prob)` 越大
- 前面加负号后，损失越小

于是“把正确答案概率推高”就自然等价于“让损失下降”。

## 为什么错得越离谱，惩罚会更大

负对数概率还有一个很重要的性质：

> 当模型给真实答案的概率非常低时，惩罚会明显变大。

这很合理。

如果真实 token 本来就很应该被预测到，但模型却只给了极低概率，那么这说明它当前判断偏得很严重，应该受到更强惩罚。

相反，如果模型已经给了真实答案很高概率，那么损失自然应该比较小。

这使得损失不只是“对错二元判断”，而能表达：

> 模型到底偏得有多严重。

## 信息量为什么会和低概率联系起来

信息论里一个很有帮助的直觉是：

> 越不常见、越出乎意料的事件，携带的信息量越大。

如果某件事本来概率极高，它发生时不会让你太惊讶。

如果某件事概率极低，它发生时就很“出乎意料”。

对数在这里再次出现，是因为信息量通常可以和概率的负对数关联起来理解。

你现在不必先掌握完整信息论体系，但至少可以先带走这个联系：

> “低概率”与“高惊讶度”天然相连，而训练损失本质上就在惩罚模型对真实答案的惊讶。

## 这和交叉熵有什么关系

交叉熵暂时可以先抓住一个非常工程化的理解：

> 它在衡量模型给出的分布，对真实目标有多不合适。

对单个正确类别来说，交叉熵会退化成“看模型给真实类别分了多少对数概率”。

因此在语言模型的 next-token 训练里，很多时候你看到的交叉熵和负对数似然其实紧密相关。

这也是为什么它会成为分类和语言建模里极其常见的损失定义。

## 为什么长序列训练时，对数尤其自然

语言模型不是只预测一步，而是在很多位置都做 next-token prediction。

如果你从整段序列的角度看，这件事更像：

- 每个位置都有一个条件概率
- 整段序列的“合理程度”与这些条件概率共同有关

这时对数特别自然，因为它让“整段序列”的目标变成：

> 各位置对数概率的求和或平均。

于是训练既能看作在优化整段序列，也能看作在优化每个位置的局部监督。

## 为什么困惑度也会和这里连起来

后面进入评估时，你会看到 `perplexity`。

它之所以和训练损失关系很近，就是因为：

- 困惑度本质上也是从对数概率或交叉熵这条线长出来的

所以如果你现在已经接受：

- 概率分布是任务对象
- 对数让长序列目标更自然
- 负对数概率天然能做损失

那么后面理解困惑度就会容易得多。

## 这一章真正要你建立的不是公式，而是路线图

你现在最该稳住的路线图是：

1. 语言模型输出条件概率分布  
2. 训练希望真实 token 概率变高  
3. 用负对数概率可以自然把这个目标写成最小化问题  
4. 多个位置的训练目标会沿序列累加或平均  

一旦这个路线图清楚了，后面再看 softmax、交叉熵和 perplexity，你看到的就不再是几块孤立公式，而是一条连续逻辑链。
