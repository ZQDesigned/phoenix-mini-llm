# 04. 因果注意力与 mask

## 如果不加约束，Attention 会马上破坏任务定义

到这里你已经知道：

- Attention 能让当前位置按内容读取历史
- Q/K/V 会决定读取路径和内容加权方式

但还有一个致命问题必须立刻补上：

> 语言模型在训练时，当前位置绝不能偷看未来。

为什么要把这件事说得这么重？

因为如果没有这个约束，Attention 机制本身会非常乐意去看后面的真实 token。那样做在数值上很容易让训练变得“看起来很好”，但学到的任务已经错了。

## 为什么自回归语言模型只能看左边

我们训练的目标是：

> 给定前文，预测下一个 token。

因此在位置 `t` 处，模型合法可见的信息只能来自：

- 当前位置之前
- 通常也包括当前位置自身

而不能来自：

- `t+1`
- `t+2`
- 更右边的未来位置

这不是一种偏好，而是任务定义本身。

如果未来位置被开放，模型就不再是在做真正的 next-token prediction。

## “偷看未来”为什么会让训练看起来更好

这是一个很容易误导人的点。

如果模型能看到正确答案，它当然更容易把正确 token 的概率推高。

于是你可能得到：

- 很漂亮的 loss
- 很顺滑的训练曲线
- 表面上像是模型学得飞快

但这些好结果建立在一个错误前提上：

> 模型被允许使用推理阶段根本不存在的信息。

所以这种“更好”是假的。它不是任务学得更好了，而是作弊了。

## causal mask 到底在做什么

causal mask 的作用非常直接：

> 把当前位置对未来位置的注意力连接屏蔽掉。

这意味着在注意力打分矩阵里：

- 左侧和当前位置可以被访问
- 右侧未来位置被强制设为不可用

于是模型在计算注意力权重时，根本不会把未来位置当作合法候选。

换句话说，mask 不是训练后再纠错，而是在相关性计算阶段就提前规定：

> 哪些位置属于当前可见上下文。

## 为什么这件事不是工程细节

很多人第一次做模型实现时，会把 mask 看成类似：

- 某个 tensor 小技巧
- Attention 里的一个附加参数
- 少写了也许只是效果差一点

这三种理解都不够准确。

更准确的判断是：

> 如果 causal mask 错了，你实现的就不是我们想训练的自回归语言模型。

这说明 mask 的地位更接近：

- 任务定义约束
- 可见性规则

而不是可有可无的工程增强项。

## 为什么训练和推理都依赖同一条因果规则

训练时：

- 模型看到真实前文
- 目标是右边一个 token

推理时：

- 模型也只能看到已经生成出来的前文
- 然后继续预测下一个 token

这意味着训练和推理共享同一条因果结构约束：

> 所有决策都只能建立在当前可见的左侧上下文上。

因此 causal mask 并不是只为训练服务，也不是只为推理服务，而是整个自回归设定的一部分。

## 为什么当前位置通常可以看自己

你可能会问：

> 如果目标是预测“下一个 token”，为什么当前位置还能看自己？

因为在实际实现里，“当前位置的表示”通常仍然是用来服务预测右边那个 token 的。

只要目标对齐方式正确，也就是：

- 当前位置的输出去对齐右边一位的目标

那么让当前位置使用自己这一位的输入表示并不会破坏任务。

真正不能看的，是目标那一位以及更右边的未来内容。

## padding mask 与 causal mask 为什么不能混为一谈

如果 batch 里存在补齐位置，你还可能需要 padding mask。

它的作用是：

> 屏蔽掉那些只是为了对齐张量形状而加入的无效占位位置。

而 causal mask 的作用是：

> 屏蔽未来位置，维持自回归可见性规则。

两者都叫 mask，但解决的是不同问题：

- padding mask 处理无效位置
- causal mask 处理未来可见性

把这两者混在一起，是实现中常见的认知错误。

## 为什么这会直接影响生成行为

如果训练时没有正确使用因果 mask，模型在训练阶段就会依赖未来答案。

但推理时未来答案不存在，于是会发生一种典型断裂：

- 训练 loss 好像不错
- 真正生成时却明显崩掉

这也是为什么一旦出现“loss 看着还行，但生成表现离谱”，mask 总是必须优先排查的对象之一。

## 这一章真正要记住的核心句子

如果这一章只记一句话，它应该是：

> causal mask 的作用不是优化 Attention，而是确保自回归语言模型始终只依据左侧可见上下文做预测；没有这条约束，模型虽然可能得到好看的训练数值，但学到的任务已经不是 next-token prediction。
