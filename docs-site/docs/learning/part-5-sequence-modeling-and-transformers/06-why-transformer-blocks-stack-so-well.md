# 06. Transformer block 为什么能反复堆叠

## Transformer 的最小可重复单元不是“Attention 层”

很多初学者在开始理解模型结构时，会自然把 Attention 看成最核心层，于是容易产生一个误解：

> 既然 Attention 已经负责读上下文，那模型主体是不是就是很多层 Attention 直接堆起来？

真正更准确的答案是：

> 可重复堆叠的基本单元通常不是单独的 Attention，而是完整的 Transformer block。

因为一个可训练、可堆叠的深层结构，还需要同时解决：

- 跨位置通信
- 逐位置非线性加工
- 深层信息流保留
- 数值稳定性

而这些事情并不是靠 Attention 一个人完成的。

## 一个 block 可以先看成两次“修正”

很多现代 decoder-only 结构用简化形式可以写成：

```python
x = x + Attention(Norm(x))
x = x + FFN(Norm(x))
```

这两行非常重要，因为它暴露了 block 的主要骨架：

- 归一化
- Attention
- 残差连接
- FFN

如果再把位置方法考虑进来，你就得到了一轮非常完整的表示更新过程。

## 残差连接为什么是堆叠能力的关键

如果没有残差，每一层都必须完全重写输入表示。

这会带来两个问题：

- 有用信息更容易在层层变换中被覆盖
- 深层训练时梯度更难健康传播

残差连接把每一层改成了：

> 先保留旧表示，再在上面叠加一份修正。

这会让深层网络更像是在逐层精炼，而不是层层重置。

对于 Transformer 来说，这一点尤其关键，因为它往往需要堆很多层才能形成更高阶上下文表示。

## 归一化为什么和残差一起重要

层数一多，隐藏状态的尺度就很容易飘。

如果某些维度越来越大、某些维度越来越小，后续：

- Attention 打分
- 线性投影
- 激活函数

都会变得更难稳定工作。

归一化的价值就在于：

> 在进入关键计算之前，把当前表示整理到更稳定的数值形态。

它不是让模型“更聪明”，而是让模型：

> 更容易在很多层上持续学下去。

## FFN 为什么不能被删成“Attention 就够了”

Attention 负责的是跨位置读取。

但读取完之后，当前位置还需要对自己拿到的新信息做更强的内部加工。

这正是 FFN 的职责。

你可以先把它记成：

- Attention：我该看哪里
- FFN：我看完之后怎样消化这些信息

如果没有 FFN，模型仍有跨位置通信能力，但每个位置内部的非线性加工会明显不足。

所以 block 之所以强，不是因为它有一个炫目的 Attention，而是因为它同时拥有：

- 跨位置读取
- 逐位置加工

这两种互补能力。

## 为什么 block 的输入输出通常保持同形状

在多数实现里，一个 block 会保持：

\[
[B, T, H] \rightarrow [B, T, H]
\]

这件事带来几个很大的结构好处。

### 第一，便于连续堆叠

上一层的输出可以直接喂给下一层。

### 第二，残差连接天然成立

因为输入输出形状一致，才能直接相加。

### 第三，整台模型像在同一个隐藏空间里反复改写表示

这让你更容易把深层 Transformer 理解成：

> 对同一批位置表示做很多轮不同深度的精炼。

## 为什么说 block 是“可重复砖块”

一个真正适合作为深层架构砖块的单元，通常应该满足：

- 输入输出接口清晰
- 自己内部职责完整
- 可以无缝接在前一层后面
- 堆很多层时仍然有希望稳定训练

Transformer block 恰好满足这些条件。

它把：

- 位置感知
- 注意力读取
- 非线性加工
- 残差
- 归一化

组合成了一个稳定、可复用的结构模板。

这就是为什么现代语言模型常常看起来像：

> embedding + N 个 block + 输出头

## 为什么深层 block 不只是“把同样操作重复 N 次”

结构模板虽然重复，但不同层通常会学出不同的统计角色。

浅层更可能偏向：

- 局部模式
- 短程依赖
- 基本边界线索

更深层可能逐步形成：

- 更复杂的主题相关性
- 更高阶的依赖结构
- 更抽象的上下文表示

所以“堆叠”不只是参数变多，而是：

> 模型获得了多轮反复读取、重写、再读取的机会。

## 这一章真正要记住的核心句子

如果这一章只记一句话，它应该是：

> Transformer 能堆很深，不是因为 Attention 单独足够强，而是因为 block 把注意力读取、逐位置非线性加工、残差保真和归一化稳定性组合成了一个输入输出接口统一、适合重复叠加的结构单元。
