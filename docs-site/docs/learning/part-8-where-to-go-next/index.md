# Part 8. 从小模型走向更大世界

这一卷的目标不是把初学者立刻推进另一套工业级训练系统，而是回答一个很自然的问题：

> 当我已经能理解并实现一个小型语言模型后，应该怎样看待更大的模型世界？

如果没有这一卷，很多读者会在完成一个学习项目之后立刻掉进新的混乱：

- 预训练和微调是什么关系
- 指令跟随和对齐是不是同一件事
- LoRA、量化、部署这些词为什么总在后续出现
- 大模型是不是只是把参数放大

## 这一卷接下来的章节规划

后续会逐步建立下面这张世界地图：

1. 小模型与大模型之间哪些概念是连续的  
2. 预训练、微调与任务适配的层次关系  
3. 指令数据、对话数据与监督微调的基本逻辑  
4. 对齐、偏好优化和安全约束为什么会出现  
5. LoRA、QLoRA、量化与部署分别在补什么工程缺口  
6. 从本项目继续向更复杂系统进阶时，哪些部分会新增复杂度  

这一卷更像全局地图，而不是第二本操作手册。它的职责是让读者知道：

> 学完这个小型模型项目之后，哪些方向是自然延伸，哪些方向需要新的工程层次与理论准备。
