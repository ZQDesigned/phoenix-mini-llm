# Part 7. 推理、评估与调试

训练结束之后，真正困难的问题往往才刚开始出现：

- loss 看起来正常，但生成质量很差
- 样例输出有点像语言，却明显不稳定
- 模型能继续训练，但你不确定哪里正在悄悄出错

这一卷的职责，就是把“如何使用模型”和“如何判断模型状态”放回同一条主线上。

## 这一卷接下来的章节规划

后续会系统展开：

1. 自回归生成到底是在怎样滚动执行  
2. greedy、temperature、top-k、top-p 怎样改变分布  
3. 为什么生成质量和训练 loss 不总是同步  
4. KV cache 在推理里到底节省了什么  
5. 困惑度、验证集与定性样例分别能说明什么  
6. 小数据过拟合测试为什么是最强链路检查手段之一  
7. 怎样把 bug 分成数据、模型、训练、采样四类去排查  

对学习项目来说，这一卷非常关键，因为一个人是否真的掌握了模型，通常不取决于“是否跑通过一次”，而取决于：

> 当结果不对时，他是否知道怎样缩小范围并修复。
