# 03. greedy、temperature、top-k 与 top-p 各在控制什么

## 为什么采样策略会让同一个模型像换了性格

很多人第一次做生成实验时，最惊讶的事情往往不是模型会写字，而是：

> 明明模型权重没变，只改了几个采样参数，输出风格却明显像变了一个模型。

这并不神秘。

因为模型学到的是一个分布，而不是一条固定答案。采样策略决定的是：

- 你如何使用这个分布
- 你允许多大程度的不确定性外显
- 你愿意多严格地偏向最高概率候选

所以采样参数改变的，不是模型知识本身，而是：

> 模型知识向外显行为投影的方式。

## 先从最朴素的策略开始：greedy

greedy 的规则非常直接：

> 每一步都选当前概率最大的 token。

它的好处很容易理解：

- 简单
- 结果稳定
- 同样输入通常可重复复现

所以 greedy 常常是一个很好的基线。

如果连 greedy 结果都完全失控，那你通常应先怀疑：

- 模型训练质量
- tokenizer / special token
- 生成链路本身

而不是先讨论复杂采样。

## greedy 为什么常常又不够

因为“每一步都只取第一名”会带来一个天然偏向：

> 它永远沿着当前最保守、最确定的局部路径走。

这会产生几类常见问题：

- 文本容易越来越模板化
- 容易陷入高频重复
- 多样性很差
- 某些本来同样合理的次高概率延续永远没有机会出现

所以 greedy 虽然稳定，但并不总是最自然的生成方式。

## temperature 到底在控制什么

temperature 作用的不是最终 token，而是：

> 对当前分布“尖锐程度”的控制。

更准确地说，它通常在 softmax 之前对 logits 做缩放。

这意味着它改变的是：

- 高低分候选之间的差距会被放大还是压平

## 温度低时会发生什么

当 temperature 较低时，较高 logits 会更占优势。

直觉上看：

- 分布更尖
- 最大概率候选更强势
- 输出更保守、更确定

如果你把 temperature 压得很低，行为会越来越接近 greedy。

它的优点是：

- 更稳
- 更少跑偏

但代价也很明显：

- 更容易重复
- 更缺少变化

## 温度高时会发生什么

当 temperature 提高时，分布会被压平。

这意味着：

- 次高概率候选更容易被选中
- 模型会显得更“敢写”
- 输出可能更有变化

但同时也意味着：

- 更容易跳到不够稳的候选
- 更容易产生不连贯和失控片段

所以高温度不是“更聪明”，而是：

> 更开放地释放了分布中的不确定性。

## 为什么 temperature 不等于随机强度的全部

很多人会把 temperature 理解成：

> 一个从保守到随机的单独旋钮。

这只对了一部分。

因为 temperature 控制的是：

- 分布的整体平滑程度

但它并不会直接回答：

- 尾部极低概率候选要不要禁止
- 候选空间该保留几个
- 保留固定数量，还是固定概率质量

这些事情就需要 `top-k` 和 `top-p`。

## top-k 在控制什么

top-k 的核心规则是：

> 只保留当前分布里概率最高的前 `k` 个候选，其余全部视为不可选。

这等于在问：

> 我最多愿意让多少个候选参与本轮决策？

它的优点是很直观：

- 候选空间被硬性限制
- 许多极低概率尾部 token 会被直接切掉
- 生成更不容易突然乱跳

## top-k 的代价是什么

因为它保留的是“固定数量”而不是“固定概率质量”，所以会有两个问题。

### 第一，分布很尖时也可能保留太多候选

如果当前第一名已经远强于其他 token，保留前 50 名也许没有太大必要。

### 第二，分布很平时又可能保留太少

有些上下文本来就比较开放，此时只允许固定少数候选，可能过度压缩多样性。

这说明 top-k 的控制方式虽然简单，但不够自适应。

## top-p 在控制什么

top-p，或 nucleus sampling，解决的正是上面这个问题。

它的核心规则不是保留固定数量候选，而是：

> 保留累计概率达到阈值 `p` 所需的最小候选集合。

也就是说，它控制的是：

> 本轮解码愿意保留多少“总概率质量”。

这会让候选集合根据当前分布形状自动伸缩。

## top-p 为什么通常比 top-k 更灵活

因为它按“概率质量”而不是“候选个数”做截断。

如果当前分布特别集中：

- 前几个 token 就已经占了大部分概率
- top-p 会自然只保留很小集合

如果当前分布比较分散：

- 需要更多 token 才能凑够设定概率质量
- top-p 会自动放开更多候选

所以它更像是在问：

> 我愿意保留多少可信候选区域？

而不是问：

> 我机械地保留前多少名？

## greedy、temperature、top-k、top-p 之间是什么关系

这几个东西不是互相替代，而是作用在不同层。

### greedy

决定：

- 是否完全不采样，直接取第一名

### temperature

决定：

- 分布在采样前有多尖或多平

### top-k

决定：

- 最多允许多少个候选参与采样

### top-p

决定：

- 保留多少累计概率质量的候选

所以一个完整生成策略常常是：

> 先调 temperature 改分布形状，再用 top-k 或 top-p 限制候选空间，最后再采样。

## 为什么这些策略会显著影响重复问题

重复常常来自“模型一直沿一条高频、保守、局部最稳的路径走下去”。

从这个角度看：

- 过低的温度可能强化重复
- 过于严格的 top-k 可能强化重复
- greedy 也可能强化重复

但另一方面，如果放得过开：

- 文本可能不再重复
- 却开始变得不连贯甚至胡乱跳跃

所以采样策略的核心难点不是：

> 怎样最随机。

而是：

> 怎样在稳定和开放之间找到合适平衡。

## 为什么“更有创意”和“更好”不是同一个维度

很多人第一次提高 temperature 后，看到文本变得更花哨，就会觉得效果更好。

这未必成立。

高随机性有时只是：

- 让模型更敢冒险
- 让更多边缘候选被释放出来

这可能带来：

- 更丰富的表达
- 也可能带来更差的逻辑和一致性

所以不能把“更发散”自动当成“更强”。

对学习项目来说，更成熟的判断是：

> 采样参数改变的是行为风格和风险分布，而不是直接提升模型能力。

## 一个很实用的实验方法

如果你想真正理解采样参数在做什么，不要同时乱改所有旋钮。

更好的做法是：

1. 固定一个 prompt  
2. 先用 greedy 生成  
3. 再只调 temperature  
4. 再固定 temperature，只比较 top-k 与 top-p  

这样你更容易形成：

- 哪个参数在改变哪一层行为
- 哪些问题来自模型本身
- 哪些问题只是解码策略投射出来的结果

## 初学者最常见的误区

### 误区一：模型输出差，一定是采样不对

有时问题确实在采样，但如果模型本身没学好，再怎么调采样也很难救回来。

### 误区二：采样越复杂越高级

不是。复杂策略只是更细地控制分布使用方式，不代表必然更好。

### 误区三：一个“最佳参数组”可以通用所有任务

也不对。不同 prompt、不同任务、不同模型规模，最合适的策略都可能不同。

## 这一章最该带走的判断

最重要的是把四个旋钮各自的职责分清：

- greedy：要不要完全取第一名  
- temperature：分布要多尖或多平  
- top-k：保留多少个最高候选  
- top-p：保留多少累计概率质量  

只要这四层关系清楚，后面你看到任何生成参数组合时，就不会只会“盲调”，而会知道每个参数到底在改变哪一层决策行为。
