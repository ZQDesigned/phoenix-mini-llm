# 卷五 神经网络作为表示学习系统

> 本卷属于第二编“机器学习与神经网络”，负责把学习问题继续推进到网络内部的表示改写、输出接口与损失结构。

走到这一卷，读者已经知道：

- 学习问题必须先被定义成输入、目标和监督
- 模型首先是参数化函数
- 训练不会脱离概率、损失与梯度语言

但只靠这些地基，你还没有真正进入神经网络内部。

你仍然可能会把“神经网络”理解成下面这种松散印象：

- 线性层叠起来
- 中间加几个激活函数
- 最后一层接 softmax
- 然后就开始 `backward()`

这种理解当然比完全陌生更进一步，但它仍然不够。

因为它还没有回答一个更关键的问题：

> 神经网络为什么不是一堆常见组件的拼装，而是一台持续重写内部表示、再把这些表示接到输出分布上的学习系统？

这正是这一卷的任务。

## 为什么这一卷必须先于“优化、噪声与泛化”

在很多常见教程里，下面这些词经常被挤在同一段材料里：

- 表示
- hidden layer
- logits
- softmax
- 交叉熵
- 梯度
- 反向传播
- mini-batch
- 泛化

这样写的最大问题不是信息少，而是层次混了。

因为这里其实至少包含三类问题：

1. 神经网络内部到底在表示什么。
2. 输出端为什么经常要长成分布接口。
3. 误差怎样被翻译成参数更新。

如果这三件事同时展开，初学者会很容易产生一种“词都见过，但系统仍然像黑箱”的感觉。

所以新结构把它们拆开了：

- 本卷只处理表示、输出接口与损失。
- 下一卷再处理优化、噪声与泛化。

这样做的目的，是让你先真正看清神经网络“是什么”，再去看它“怎样学习”和“为什么会学歪”。

## 为什么神经网络首先是一台表示学习系统

“表示”不是一个故作高深的词。

它更准确地指向这样一件事：

> 模型在每一层都在重写输入的内部描述方式，让后面的判断更容易发生。

这会直接改变你理解网络的方式。

如果你把网络看成一组层叠 API，那么你看到的会是：

- 这里乘一个矩阵
- 那里过一个激活
- 最后一层吐出一串数

如果你把网络看成表示学习系统，那么你看到的会是：

- 模型在逐层重写坐标系
- 模型在逐层强调哪些方向更重要
- 模型在逐层压低哪些变化可以被忽略
- 模型最终把内部表示接到“对候选输出的偏好分布”上

这后一种视角，才是后面理解 attention、Transformer block 和语言模型主体结构时真正稳定的视角。

## 为什么这一卷要把“输出端”讲得很重

很多人第一次学神经网络时，会把真正注意力都放在中间层。

但在学习闭环里，输出端同样关键。

因为模型不是只要“算出一些数”就可以了。

它还必须解决：

- 这些数到底代表什么
- 模型怎样比较多个候选输出
- 目标信号怎样与当前输出对接
- 误差又怎样稳定地回流到前面的层

这也是为什么本卷会把下面这些内容放在核心位置：

- logits
- softmax
- 交叉熵

它们不是分类任务里“惯用的模板”。

它们是在解决一个非常实在的问题：

> 当模型面对多个可能输出时，怎样把内部偏好写成可比较、可训练、可回传误差的接口？

## 为什么这一卷对大模型学习尤其关键

很多大模型初学者会觉得：

> 反正我后面主要学的是 Transformer，这一卷是不是更像传统神经网络背景？

这其实是误判。

因为后面的语言模型主体虽然更复杂，但仍然离不开这里建立的基本视角：

- embedding 是表示
- hidden state 是表示
- attention 输出仍然是表示重组
- 最后吐出的 logits 仍然要接 softmax 与交叉熵

也就是说，Transformer 不是绕开了神经网络基础，而是在更复杂的序列世界里继续做表示学习。

如果这一卷没有读稳，后面你会经常把 attention 误学成“更高级的一层”，却说不清它到底在改写什么表示、为什么最后仍然要回到 logits 与损失。

## 本卷的两章分别在做什么

### 第一章：[01. 线性层、激活函数与表示空间](/learning/volume-05-neural-networks-and-optimization/01-linear-layers-activations-and-representations.md)

这一章先回答神经网络最核心的内部问题：

- 线性层为什么仍然是骨架
- 激活函数为什么不是小配件
- 隐藏层为什么不是无意义的中转站
- “表示空间”到底是什么意思

你会逐步建立一个关键认识：

> 神经网络的深度，不只是多几层计算，而是多几次对表示空间的重写机会。

### 第二章：[02. 概率、softmax 与交叉熵](/learning/volume-05-neural-networks-and-optimization/02-probability-softmax-and-cross-entropy.md)

这一章把网络主体接到输出端：

- 为什么输出经常不是答案本身，而是一组偏好分数
- softmax 为什么会自然出现
- 交叉熵为什么会成为训练时常见的误差表达
- 为什么“分布接口”会让优化更清楚地闭合

这一章读稳之后，你对后面语言模型输出 logits、计算 next-token loss 的理解会稳定很多。

## 这一卷想建立的长期能力

读完这一卷，最重要的不是记住几个术语定义。

更重要的是建立下面三种长期能力。

### 第一，表示视角

你不再把网络看成一堆层，而会更自然地问：

- 当前这一层在保留什么
- 当前这一层在强调什么
- 当前这一层在丢弃什么

### 第二，输出接口视角

你会更自然地把 logits、softmax 与交叉熵看成一条连续接口，而不是三个分开的名词。

### 第三，结构迁移视角

你会开始意识到：

> 后面的 attention 和 Transformer，并不是跳到另一门学科里，而是在更复杂的输入对象上继续做表示学习。

## 这一卷之后去哪里

读完本卷，最自然的下一步不是立刻跳到 tokenizer 或 Transformer。

最稳的顺序是进入：

- [卷六. 优化、噪声与泛化](/learning/volume-06-optimization-and-generalization/index.md)

因为到那时，你已经知道神经网络“长成什么样”，下一步就应该回答：

- 误差怎样被翻译成参数更新
- 训练为什么天然带噪声
- 模型为什么会在训练集上变好，却在未见数据上变差

也就是说，卷五解决的是：

> 神经网络是一台什么样的学习系统。

而卷六会继续解决：

> 这台系统怎样在真实训练里被推着前进，又为什么会在前进中暴露统计与泛化问题。
