# Part 7. 从小模型走向更大模型

这一分册的目的，不是突然把初学者拉进另一套难度完全不同的工业系统，而是回答一个自然会出现的问题：

> 当我已经能从零实现一个小型语言模型之后，接下来怎样理解更大的模型世界？

这里会逐步补上更宽的视野，例如：

- 为什么大模型不只是“把参数调大”
- 预训练、微调、指令跟随、对齐之间是什么关系
- LoRA、量化和部署为什么会成为后续常见主题
- 从小模型学习迁移到更大系统时，哪些概念会保持连续，哪些地方会新增工程复杂度

这一分册的定位更像“世界地图”，而不是“第二本训练超大模型操作手册”。

它要帮你建立的是：

> 学完这个项目之后，下一步该往哪里扩展，以及为什么那些扩展主题会自然出现。
