# Part 1. 入门与学习地图

## 这一分册要解决什么问题

很多人一上来学大模型，会直接跳进这些词：

- Transformer
- Attention
- Tokenizer
- LoRA
- KV cache

但如果一开始就这样学，最常见的结果是：

> 术语越记越多，理解并没有真正变稳。

原因很简单。你还没有先回答三个最根本的问题：

1. 语言模型到底是什么任务？
2. 为什么初学者应该先做一个小模型，而不是幻想直接做“大模型”？
3. 应该按什么顺序学习，才能避免只会抄代码？

这一分册就是先把这三个问题讲清楚。

## 这一分册的职责

它不是在教你怎么装环境，也不是在带你实现模型代码。它的职责更基础：

- 帮你建立正确的目标
- 帮你建立正确的学习顺序
- 帮你形成一张全局地图

如果这一分册没有读明白，你后面很容易出现两种偏差：

- 一种是急着追参数规模，忽视真正要学的结构理解
- 另一种是把整个项目误学成“命令行 + 框架 API”的工程拼装

## 读完之后你应该达到什么状态

读完这一分册，你应该至少能够：

- 用自己的话解释“语言模型”的任务定义，而不是只说“它会生成文本”
- 理解为什么学习阶段更适合做“小而完整”的模型
- 知道整套知识档案的阅读顺序和它与复刻教程的关系

如果你现在还不能稳定回答这些问题，不要急着进入 Transformer。先把目标摆正，后面的学习效率会高很多。
