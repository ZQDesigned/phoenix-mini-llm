# 10. 训练一个小型语言模型的基本流程

## 这一章要解决什么问题

现在你已经知道一个小型语言模型大致由什么组成，但“模型定义出来”和“模型真的学会”之间，还隔着一整条训练流程。

这一章要回答的问题是：

> 从一堆文本数据到一个会产生像样分布的语言模型，中间到底要经过哪些基本训练环节？

这部分内容确实比纯概念更接近实践，但它仍然属于任何小型语言模型都绕不开的基础知识。因为如果你不了解训练过程，后面看到：

- batch
- optimizer
- learning rate
- validation
- gradient accumulation
- mixed precision

这些词时，只会觉得它们是零散技巧，而不会知道它们在整条学习链里各自承担什么职责。

## 第一件事：训练不是“把数据塞给模型”，而是一个循环系统

语言模型训练最基本的结构可以概括成：

```text
取一批样本
-> 前向计算 logits 和 loss
-> 反向传播求梯度
-> 用优化器更新参数
-> 重复很多次
```

这看起来简单，但每一步背后都包含关键决策：

- 样本怎么分 batch
- loss 如何定义
- 学习率多大
- 更新多少步
- 何时评估

所以训练不是单个动作，而是一套重复执行的学习协议。

## 第二件事：为什么要把数据分成训练集和验证集

如果你只有一份训练数据，一直盯着训练损失看，很容易产生错觉：

> loss 在降，所以模型一定越来越好。

这并不总成立。

模型完全可能只是越来越会记住训练数据，却没有学到可泛化的规律。

### 训练集的职责

- 用来更新参数
- 让模型真正学习

### 验证集的职责

- 不参与参数更新
- 用来观察模型对未参与学习数据的表现

所以你应该尽早形成习惯：

> 训练一个模型时，至少同时关注训练损失和验证损失。

## 第三件事：为什么训练使用 batch

很多初学者会直觉地想：

> 不如一条样本一条样本地喂模型。

当然可以，但现代训练通常更喜欢 batch，原因很直接：

- 并行效率更高
- GPU/加速设备利用率更好
- 梯度估计相对更稳定

### batch 带来的代价是什么

- 显存占用上升
- 实验设计更复杂
- 数据必须能被组织成统一形状

所以 batch 不是无脑越大越好，它始终和硬件预算绑定。

## 第四件事：为什么语言模型训练时，数据通常要先被切成固定长度块

现实中的文本长度差异很大，但模型训练时更适合形状整齐的张量。

因此常见做法是：

- 把 token 流按固定上下文长度切块
- 用每块中的前 `L` 个 token 预测后 `L` 个 token

这样做的好处包括：

- batch 更容易组织
- attention 计算边界更明确
- 训练成本更可控

这说明一个重要事实：

> 训练流程从数据进入那一刻起，就已经在塑造模型“能看多长、怎么学”的基本边界。

## 第五件事：优化器到底在做什么

训练的目标不是只把 loss 算出来，而是让参数朝着降低 loss 的方向改变。

优化器负责的正是：

> 根据当前梯度，决定参数下一步怎样更新。

### 你现在最需要理解的不是优化器家族比较

而是下面这件事：

- loss 告诉你现在错得多不多
- 梯度告诉你往哪个方向调参数
- 优化器决定“怎么按这个方向走”

很多小型语言模型会使用 AdamW 一类优化器，但初学阶段最重要的不是背名字，而是理解：

> 没有优化器，模型就不会学习；优化器配置不合理，模型会学得很差。

## 第六件事：学习率为什么经常比模型结构更先决定训练成败

学习率控制的是每次参数更新的步长。

### 学习率太大

可能会导致：

- loss 抖动剧烈
- 训练不稳定
- 甚至直接数值爆炸

### 学习率太小

可能会导致：

- 学习非常缓慢
- 看起来什么都在跑，但几乎没进步

所以学习率不是训练里的普通数字，而是整个优化过程的节奏控制杆。

对初学者来说，一个很重要的判断是：

> 当模型不学习时，先别急着怀疑 Attention 写错了，学习率往往是最先要排查的对象之一。

## 第七件事：为什么很多训练会使用 warmup 和学习率衰减

训练刚开始时，模型参数仍然很随机。如果一开始就用很激进的学习率，训练可能容易不稳定。

因此很多训练会在前几步使用 warmup，也就是：

- 先从较小学习率起步
- 再逐步升到目标学习率

随后在训练后期再逐渐降低学习率，让收敛更平稳。

### 你不需要先记住所有调度曲线

但你应该知道：

> 学习率不是必须从头到尾固定不变。训练不同阶段，模型需要的更新步长可能不同。

## 第八件事：为什么梯度累积对小显存设备特别重要

如果你显存有限，就会很快遇到一个现实问题：

> 我一次根本放不下想要的 batch size。

梯度累积就是解决这个问题的常见办法。

### 它的思路是什么

不是一次处理一个大 batch，而是：

- 连续处理多个小 batch
- 每个小 batch 都做反向传播
- 但暂时不立刻更新参数
- 等多个小 batch 的梯度累积起来后，再统一更新

### 这为什么有效

因为它能在显存允许的前提下，近似模拟更大的有效 batch。

所以对小显存学习项目来说，梯度累积不是进阶技巧，而是非常核心的训练手段。

## 第九件事：为什么 mixed precision 会经常出现

在较新的 GPU 训练流程中，你经常会看到 mixed precision，也就是混合精度训练。

它的目标主要有两个：

- 节省显存
- 提升吞吐

### 但它不是“默认打开一定更好”

因为混合精度虽然常常有帮助，但也会带来：

- 数值稳定性问题
- 平台支持差异
- 调试复杂度上升

所以一个很成熟的学习顺序通常是：

1. 先确保全精度训练逻辑正确  
2. 再考虑是否引入混合精度优化

也就是说，mixed precision 首先是优化工具，不是理解训练的前提。

## 第十件事：为什么梯度裁剪会频繁出现在小模型训练里

深层网络训练时，某些 step 可能会出现非常大的梯度。

这会导致：

- 参数更新步子突然过大
- 训练短时间内变得不稳定
- loss 异常抖动甚至崩掉

梯度裁剪的核心作用是：

> 当梯度过大时，限制它的总体规模，防止更新爆炸。

它不能替代合理超参数，但能显著提高训练过程的鲁棒性。

## 第十一件事：为什么 checkpoint 是训练流程的基本组成部分

训练一个语言模型往往不会是一口气无中断完成的。

你需要面对：

- 机器重启
- 调参试验
- 训练中断
- 想比较不同阶段结果

因此 checkpoint 非常重要。

### checkpoint 至少应该保存什么

从概念上说，一个合格的 checkpoint 至少应该能恢复：

- 模型参数
- 优化器状态
- 当前训练步数
- 必要的额外训练状态

### 为什么只保存模型参数不够

因为训练不是只有“模型长什么样”，还包括“模型已经学到第几步、优化器内部状态是什么、学习率处在哪个阶段”。

所以 checkpoint 本质上保存的是：

> 一个训练过程的可恢复状态，而不是一张静态权重快照。

## 第十二件事：为什么验证必须周期性发生

很多初学者只想：

> 先把训练一路跑完，最后再看看结果。

这会让你失去过程感。

更合理的做法通常是：

- 每隔一定步数看一次训练状态
- 定期在验证集上评估
- 保存阶段性 checkpoint

这样你能更早发现：

- loss 根本没在正常下降
- 模型开始过拟合
- 某组超参数明显不合适

训练不是只有终点，过程里的诊断信号同样重要。

## 第十三件事：训练日志为什么不是装饰

训练过程中常记录的内容包括：

- 当前 step
- 训练损失
- 验证损失
- 学习率
- 生成样例或其他观察指标

这些日志的作用不是“看起来专业”，而是帮助你回答：

- 模型到底有没有在学
- 是不是在某个阶段突然变差
- 某次调参带来了什么影响

如果你不记录这些信息，后面大多数判断都只能靠印象。

## 第十四件事：一个适合学习的小模型训练流程长什么样

如果把一条合理的训练流程用概念表达出来，大致会是：

1. 准备和切分语料  
2. 训练 tokenizer  
3. 把文本转成 token 并打包成固定长度样本  
4. 构建模型  
5. 选择优化器和学习率  
6. 用训练集更新参数  
7. 周期性用验证集检查泛化表现  
8. 保存 checkpoint  
9. 训练结束后用生成样例观察模型行为

你会发现，真正的训练流程从来不是只围绕“模型前向”展开，而是数据、优化、评估共同组成的系统。

## 第十五件事：初学者最容易误解的几点

### 误区 1：训练工程只是外层脚手架

不对。训练流程直接决定模型能否真正学会。

### 误区 2：只要 loss 在降，一切就没问题

也不对。你还必须看验证集和生成行为。

### 误区 3：batch 越大越好

不对。它始终受显存和实验目标约束。

### 误区 4：mixed precision 是必须从第一天就打开的标准配置

不对。先保证训练逻辑正确，再谈优化。

### 误区 5：checkpoint 只是怕电脑关机时才有用

不对。它同样服务于比较阶段结果、恢复训练和实验管理。

> **这一章真正要你形成的训练观**
>
>   训练一个小型语言模型，不是“模型搭好以后顺手跑一跑”，而是一整条从数据、batch、优化、验证到恢复与记录的学习流程。把这条流程理解成系统，你后面才有能力稳定地做实验和调参。
