# Part 4. Transformer 与语言模型主体

这一分册是整套知识档案的中心骨架之一。

前面两件大事已经完成：

- 你知道模型为什么是在做条件分布预测
- 你知道文本怎样变成张量与监督信号

接下来真正要回答的是：

> 模型主体为什么是 Transformer，而不是别的结构？

这一分册会系统展开：

- 早期序列建模为什么不够
- Attention 在解决什么结构问题
- causal mask 为什么是任务定义的一部分
- 多头注意力、位置方法和 block 是怎样配合的
- 一个完整的 decoder-only 模型到底由哪些部件组成

它会把“Attention 是一个公式”这种过于扁平的理解，重新展开成：

> 一套内容驱动的信息路由机制，以及围绕这种路由机制组织起来的深层表示系统。

对初学者来说，这一分册不是“最先读最酷”，而应该在文本和基础训练目标之后读。因为只有这样，你才会知道每个结构部件为什么存在。
