# 01. 机器学习到底在学什么

## 为什么要先问这个问题

很多人一开始学神经网络，会迅速接触到：

- 参数
- 梯度
- loss
- optimizer

然后很快就开始“跑训练”。

如果这时你还没有先理解：

> 一个模型到底在学什么？

那么这些词会像很多分散零件一样飘在空中。

所以在进入任何具体结构之前，我们必须先把“学习”这件事本身讲清楚。

## 最朴素的说法：学习是在逼近一个有用映射

机器学习最通用的直觉可以先写成一句话：

> 给定输入，模型要学会输出我们想要的结果；而训练过程就是不断调整参数，让这个输入到输出的映射越来越接近期望。

例如：

- 图像分类：输入图片，输出类别
- 回归任务：输入特征，输出数值
- 翻译任务：输入源语言句子，输出目标语言句子
- 语言模型：输入前文，输出下一个 token 的分布

这说明一个模型最基本的工作形式是：

\[
\text{input} \rightarrow f_\theta(\text{input}) \rightarrow \text{output}
\]

这里的 `\theta` 表示参数。

所谓学习，本质上就是找到一组足够好的参数，让这个函数在我们关心的数据上表现更好。

## 参数是什么

参数可以先理解成：

> 模型内部可被训练调整的数值。

它们决定了模型看到某种输入时，会给出怎样的输出偏好。

比如在最简单的线性模型中，参数可能只是：

- 一组权重
- 一个偏置

在神经网络里，参数通常会扩展成很多层里的大批权重矩阵和偏置项。

但不管规模多大，最底层含义都一样：

> 参数决定了模型当前“怎么看待输入”。

## 数据为什么是学习的老师

模型不会凭空知道什么输出是好结果。它需要从数据中得到信号。

训练数据最重要的价值不在于“它很大”，而在于：

> 它提供了输入与目标之间的对应关系。

对于语言模型，这种对应关系有点特殊。它不是人工手写标签，而是直接来自原始文本本身：

- 给模型前文
- 把后一个 token 当成目标

所以语言模型的监督信号，本质上是从文本序列内部自动构造出来的。

## 学习为什么需要损失函数

光有输入和目标还不够，模型还需要一个办法知道：

> 我当前到底错得多不多？

这就是损失函数的作用。

损失函数会把“预测”和“目标”之间的差距压成一个数值。

例如：

- 预测越接近目标，loss 越小
- 预测越偏离目标，loss 越大

于是训练就有了一个清晰目标：

> 想办法让 loss 下降。

这听起来简单，但后面所有训练机制几乎都围绕这件事展开。

## 学习不是把 loss 记下来，而是用 loss 改参数

这是很多初学者第一次接触训练时会忽略的重点。

loss 的价值不在于“我知道自己错了”，而在于：

> 我能利用这个错误信号去调整参数。

也就是说，训练过程真正发生的事情不是：

1. 算出一个 loss  
2. 看它大不大  

而是：

1. 前向得到预测  
2. 计算 loss  
3. 反向求出参数该怎么改  
4. 更新参数  

所以“学习”并不是 loss 自己发生了魔法，而是：

> loss 作为优化目标，驱动了参数更新。

## 为什么模型能从很多样本里学到一般规律

如果模型只是对每个样本单独记忆，它当然也可能把训练集吃下来，但那不叫真正的学习。

真正更有价值的情况是：

> 模型在很多样本中找到了稳定的统计规律，因此能在没见过的新样本上也表现得更好。

这就叫泛化。

例如，一个语言模型如果真正学到的是：

- 汉语里某些词常怎样搭配
- 英语里某些语法结构常怎样延续
- 某类上下文里某些 token 更高概率

那么它就不需要见过完全相同的句子，也能给出合理预测。

## 神经网络为什么比简单规则更强

如果任务很简单，我们可以手工写规则。

但现实中的语言、图像、声音任务都非常复杂，输入到输出的关系很难被人类完整写死。

神经网络之所以有价值，不是因为它“神经”这个名字很厉害，而是因为：

> 它提供了一种参数化、可微、可训练的函数族，能够通过数据自动拟合复杂映射。

换句话说，它让“写规则”变成了“设计一个可学习结构，再让数据去调整其中的参数”。

## 语言模型的学习任务和普通分类有什么相同点

尽管语言模型看起来很复杂，但从某个角度看，它和普通分类任务有一个强连续性：

- 输入一段上下文
- 输出对若干候选类别的分布

在图像分类里，类别可能是：

- 猫
- 狗
- 汽车

在语言模型里，类别则是整个词表中的 token。

这就是为什么后面会出现：

- logits
- softmax
- cross-entropy

因为从训练目标角度看，它依然是一类分布预测问题。

## “学习”并不保证“理解世界”

一个重要但容易混淆的问题是：

> 模型学会了，是否就等于它像人一样理解了世界？

对当前阶段，更稳妥的回答是：

> 学习首先意味着模型学会了在训练目标下稳定降低误差，而不是 automatically 获得了人类式理解。

语言模型当然会在语言中吸收大量世界模式，但从训练定义上看，它学到的首先仍然是：

- 输入和目标之间的统计关系
- 哪种输出在当前条件下更可能

这能产生很强能力，但不要把“学会了任务”直接等同于“获得了完整理解”。

## 这一章真正要记住的核心句子

如果这一章只留一句话，那应该是：

> 机器学习最本质的事情，是通过数据与损失函数提供的误差信号，不断调整参数，使一个输入到输出的映射越来越接近我们关心的目标行为。

后面所有神经网络、语言模型、训练工程，都会是这句话的具体展开。
