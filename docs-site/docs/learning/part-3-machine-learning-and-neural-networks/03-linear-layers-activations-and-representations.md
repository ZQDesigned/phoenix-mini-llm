# 03. 线性层、激活函数与表示空间

## 为什么这一章重要

当你第一次看神经网络代码时，很快就会遇到两类操作：

- 线性层
- 激活函数

如果你只把它们理解成“标准组件”，你后面看任何模型都会停留在 API 层。

这一章真正要解决的问题是：

> 为什么模型需要把输入向量不断投影、再经过非线性变换？这在本质上改变了什么？

## 线性层在做什么

线性层最朴素的形式是：

\[
y = Wx + b
\]

你可以先把它理解成：

> 用一组可学习参数，把原来的表示重新映射到另一个向量空间。

这里最关键的不是公式长什么样，而是它提供了三种能力：

- 重新组合输入特征
- 改变表示空间的方向
- 改变输出维度

假设输入向量有 4 个维度，线性层并不是简单把第 1 维复制到输出第 1 维，而是：

> 用输出空间中的每个维度，对输入各维做一组加权组合。

所以线性层的本质是“学一个可调的坐标变换”。

## 只有线性层为什么不够

这是神经网络基础里最重要的事实之一。

如果你把很多个纯线性层连在一起，例如：

\[
W_3(W_2(W_1x))
\]

它们整体上仍然等价于一个更大的线性变换。

也就是说：

> 只堆线性层，不会神奇地产生复杂非线性能力。

这就是为什么神经网络必须引入激活函数。

## 激活函数为什么必要

激活函数的核心作用是：

> 在层与层之间引入非线性。

一旦有了非线性，模型就不再只能表达单一线性映射，而能逐步逼近更复杂的函数关系。

这意味着模型可以学会：

- 更复杂的模式边界
- 更高阶的特征组合
- 更丰富的表示变换

所以激活函数不是某种附属小技巧，而是神经网络之所以有表达力的关键原因之一。

## 可以把激活函数想成“折弯空间”

一个很有帮助的直觉是：

> 线性层在重新摆放坐标系，激活函数在把空间折弯。

如果只有线性层，空间虽然会旋转、拉伸、缩放，但始终保持线性结构。

加入激活函数之后，模型才真正有机会把复杂模式拆开。

这也是为什么“线性 + 非线性 + 线性 + 非线性”的叠加，会比单纯一堆矩阵乘法强得多。

## 常见激活函数不需要全记，但要知道它们的角色

你可能会看到：

- ReLU
- GELU
- SiLU
- SwiGLU 中的门控激活

初学阶段不必一开始背完每个公式差别，但应该稳稳理解它们共同承担的职责：

> 提供非线性，让模型能够学习更复杂的表示变换。

不同激活函数的细节会影响：

- 平滑程度
- 梯度行为
- 训练稳定性

但“为什么一定要有激活函数”比“哪一个最流行”重要得多。

## 什么叫表示空间

这是另一个需要尽早建立的概念。

当我们说一个 token、一个位置、一个样本在模型内部被表示成一个向量时，这个向量所在的空间就是表示空间。

表示空间不是一个虚构名词，它意味着：

- 每一维都可以承载某些统计特征
- 向量之间的方向和距离能反映某些模式关系
- 线性层会不断把表示从一个空间映射到另一个空间

语言模型中的 hidden state，本质上就是在不同层之间不断被改写的表示。

## 为什么“表示”比“原始符号”更强

以 token 为例，原始 token id 只是离散编号。

编号本身不能表达：

- 哪些 token 语义更近
- 哪些 token 常出现在类似上下文
- 哪些 token 在当前语境下功能相似

而一旦进入连续表示空间，模型就可以通过向量关系表达这些统计规律。

所以 embedding、hidden state、attention 中的 `Q/K/V`，本质上都可以看成：

> 不同阶段、不同用途下的表示。

## 线性层不仅在“算结果”，也在“改写表示”

这点非常关键。

很多初学者把线性层只当成通往最终输出的一步计算。其实在深层网络里，大部分线性层更重要的职责是：

> 把当前表示变换成更适合下一步处理的形式。

例如：

- embedding 后的表示进入 block 前，需要变成适合注意力比较的样子
- hidden state 在 FFN 中，需要进入更宽的中间空间再回来
- 最终输出前，需要从 hidden space 映射到 vocab space

这说明线性层不是单一用途，而是在不断重塑表示空间。

## 为什么语言模型里会反复看到“投影”

“投影”这个词本质上就是：

> 把一个向量从当前表示形式映射到另一个表示形式。

在语言模型里你会反复看到：

- token embedding
- Q/K/V projection
- output projection
- FFN expansion / contraction

这些操作虽然细节不同，但背后共享同一个思想：

> 为了完成不同阶段的计算，模型需要把表示变成不同用途的版本。

## 这一章真正要记住的核心句子

如果这一章只记住一句话，它应该是：

> 线性层负责重组和投影表示，激活函数负责引入非线性；神经网络之所以强，不是因为堆了很多矩阵，而是因为它在多层表示空间之间反复做“线性变换 + 非线性改写”。
