# 01. 线性层、激活函数与表示空间

这一章是很多读者第一次真正走进神经网络内部的地方。

到这里为止，你已经知道：

- 一个学习问题至少要有样本、目标、预测和损失
- 模型可以被看成带参数的函数
- 线性模型为什么是最透明的起点

但如果要继续往前走，你迟早会遇到一组不断重复出现的词：

- 线性层
- 激活函数
- 隐藏层
- 表示
- projection
- hidden state

你会在最简单的 MLP 里看到它们。
你会在分类器里看到它们。
你会在 Transformer 里反复看到它们。

可仅仅认识这些名字，并不等于你真的知道神经网络在做什么。

很多初学者会卡在一种非常典型的中间状态：

- 知道 `Linear` 是一个常用层
- 知道 `ReLU`、`GELU` 是激活函数
- 知道网络会一层层往前算
- 也知道最后会 `backward`

可如果继续追问：

- 线性层到底在“读”输入里的什么
- 激活函数为什么不是可有可无的小修饰
- 为什么神经网络总在谈“表示”
- 隐藏层到底在保存什么东西
- 为什么同一个对象经过很多层后，会越来越适合当前任务

很多人就会开始失去稳定解释能力。

这说明问题不在于你没见过公式。
问题在于你还没有把这些公式看成一条连续的表示加工链。

这一章要解决的正是这个断裂。

更准确地说，本章要回答四个互相咬合的问题：

1. 线性层到底在对输入做什么。
2. 为什么只有线性层远远不够。
3. 激活函数到底在补什么结构能力。
4. 什么叫“表示”，为什么现代模型本质上都在学习表示。

如果这四件事能真正站稳，后面你再去看：

- embedding
- hidden state
- Q / K / V projection
- FFN
- residual stream
- logits

你看到的就不再是一堆独立零件，而是一条持续改写内部表示的计算链。

## 神经网络首先不是“很多层”，而是一台表示改写机器

很多人对神经网络最粗糙的理解是：

- 输入一些数字
- 中间经过若干层
- 输出一个结果

这当然不完全错误，但它太弱了。

更有力量的说法是：

> 神经网络首先是一台不断改写表示的机器。

这里的“表示”不是一个故作高深的术语。
它真正指的是：

> 模型此刻用什么方式组织、压缩、突出和重写输入信息，使它更适合后续任务判断。

这件事非常重要，因为它会直接改变你理解网络结构的方式。

如果你把神经网络看成一组 API 的堆叠，那么你看到的往往只是：

- 这里乘一个矩阵
- 那里加一个偏置
- 中间过一个激活
- 最后吐出一串数

这种观察不能说错，但它几乎不会留下长期直觉。

如果你把神经网络看成表示改写系统，那么你看到的会是另一条主线：

- 这一层想从当前对象里读出什么模式
- 这一层把哪些变化保留下来
- 这一层把哪些变化压低或忽略
- 这一层输出的新对象，为什么会更适合下一层继续处理

这后一种视角，才是真正稳定的视角。

因为后面你再看到 attention、残差流、前馈网络、隐藏状态时，都还会反复回到这件事上：

> 模型不是在“做更多计算”而已。
> 它是在不断把当前对象改写成更适合任务的新表示。

## 线性层的本质不是“连得多”，而是“重新定义读取方向”

很多入门材料介绍线性层时，会说：

> 它把所有输入神经元和所有输出神经元都连起来。

这句话从实现角度不算错，但它很容易把理解带偏。

因为它会让初学者停留在一种很浅的印象里：

- 这层很强
- 因为它连接很多

更接近本质的说法应该是：

> 线性层在学习一组可调整的读取方向和重组规则。

也就是说，它的重要性不在于“连接很多”，而在于：

- 它能沿许多不同方向读输入
- 它能把读出来的结果重新组织成新的坐标系
- 它能为下一步计算定义一个更合适的表示空间

这是理解线性层最关键的入口。

神经网络不是靠“连接感”取胜的。
它是靠“表示改写能力”取胜的。

而线性层，就是最基础的表示改写器。

## 从单个输出神经元重新理解线性层，会比直接背矩阵式更稳

我们先不要急着进一整层。
先回到最简单的情形。

假设这一层只输出一个标量：

\[
z = w^\top x + b
\]

这里的 `w` 可以看成一组权重。
你也可以把它理解成：

> 这一维输出拿着一张可学习的问题模板，去问输入：“你在这个方向上的响应有多强？”

这句话非常重要。

因为它让你看到：

- 输出维度不是凭空出现的
- 每个输出维都在对应某种读取方向
- 权重向量 `w` 定义了“怎么读”
- 偏置 `b` 定义了“默认基线在哪”

如果某个输出维变得很大，往往意味着：

> 输入在这组权重所代表的模式方向上，响应得很强。

所以单个输出神经元最自然的理解方式，不是“一次乘加”而已，而更像是：

- 一个模式探测器
- 一个方向响应器
- 一个可学习的问题

一旦这样理解，很多后面的概念都会变得顺。
例如：

- 为什么不同输出维会学出不同职责
- 为什么一层可以同时并行读很多模式
- 为什么某些输出维会和某种局部结构特别相关

## 从单个输出维到一整层，本质上是在并行提出很多可学习问题

当输出不止一个维度时，你就得到一整层：

\[
y = Wx + b
\]

其中：

- \(x \in \mathbb{R}^{d_{in}}\)
- \(W \in \mathbb{R}^{d_{out} \times d_{in}}\)
- \(y \in \mathbb{R}^{d_{out}}\)

你当然可以把它读成一个矩阵乘法。
但更稳定的理解方式是：

> 这一层正在并行发出 \(d_{out}\) 个不同的可学习提问，然后把输入沿这些提问方向重新投影。

每一行权重都在代表一种读取模式。
整层一起工作时，模型不是只得到一个判断，而是得到一组新的中间描述。

于是，线性层不再只是“把输入变成输出”。
它在做的其实是：

> 把当前对象翻译进另一个表示空间。

这句话非常关键，因为它解释了为什么同样是线性层：

- 有时它负责降维
- 有时它负责升维
- 有时它负责把同一个对象重新写到另一个空间里
- 有时它只是为下一层准备一个更好加工的中间表示

所以线性层本质上不只是“算分”。
它是在“换一种说法来描述当前对象”。

## 偏置不是小补丁，它在决定默认参考面

很多初学者学线性层时，会把偏置看成一句附带说明：

> 就是再加一个 \(b\)。

这会低估偏置的作用。

如果没有偏置，线性变换只能围绕原点组织表达。
这意味着模型对很多模式的响应会被迫受到“必须穿过原点”的限制。

引入偏置之后，模型等于获得了一个更灵活的参考面。
它不必总从原点出发判断“这个方向有多强”，而可以把默认基线挪到更合理的位置。

如果从最朴素的话说，偏置在补的是：

> 即使所有输入维都为零，输出层也不一定应该被迫认为“这里就是绝对零响应”。

所以偏置让模型学到的，不只是“不同方向如何加权”，还包括：

> 从哪条基线开始判断才合理。

这就是为什么真实实现里，偏置长期都不是无足轻重的边角项。

## 只堆线性层并不会自动让模型变强，因为线性会塌缩成一次整体线性变换

讲到这里，真正的分界线就该出现了。

很多初学者都会自然以为：

> 那我多堆几层线性层，不就更强了吗？

这是一个非常自然、也非常值得认真对待的误解。

如果你把很多线性层直接连在一起，但中间完全没有非线性，那么整个系统仍然等价于一个更大的线性变换加偏置。

也就是说：

\[
W_3(W_2(W_1x+b_1)+b_2)+b_3
\]

表面上像很多层，实际上仍然可以合并成：

\[
W'x + b'
\]

这意味着：

> 只把线性层堆高，并不会真正打破线性模型的表达上限。

模型看起来更深了，但它仍然只是在做“一次整体线性改写”。

这件事的后果非常大。

它说明真正让神经网络和线性模型分道扬镳的，不是“层数变多”本身，而是：

> 中间必须插入非线性。

## 激活函数在补的，不是装饰，而是“不同区域用不同规则响应”的能力

只要接受“纯线性堆叠会塌缩”，激活函数的重要性就不再像一条需要硬背的结论。

它之所以必须出现，是因为模型需要获得一种线性层单独做不到的能力：

> 让不同输入区域触发不同的响应方式。

线性变换很擅长整体重写空间。
但它不擅长说：

- 这片区域按一种方式响应
- 那片区域按另一种方式响应
- 某些方向上的变化应该被截断
- 某些方向上的变化应该被柔和放大

一旦插入非线性，这种事情就变得可能了。

于是模型不再只是不断旋转、平移和重组同一个线性空间。
它开始能够：

- 折叠空间
- 分段响应
- 门控不同模式
- 让不同条件下的信息流表现不同

如果只用最朴素的话说，激活函数补上的就是：

> 让模型不再被迫对所有输入都用同一种线性规则说话。

这正是神经网络和线性模型的根本分界线。

## 用更直观的话说，激活函数像是在做“门控”与“放行”

很多读者一看到激活函数就会卡在公式层面。
其实先抓直觉更重要。

你可以把它想成一种局部门控机制。

它在回答：

- 当前这条中间响应应该被保留多少
- 当前这条响应应该被压掉还是放大
- 哪些弱小信号干脆可以被视作“不值得继续传”
- 哪些信号应该更柔和地进入下一层

这样一来，激活函数不再只是“再套一个函数”。
它是在持续决定：

> 哪些中间模式值得继续往后传，哪些模式应该被削弱或切断。

这个视角非常重要。

因为一旦你进入 Transformer，后面的门控前馈层、注意力权重、甚至残差路径的理解，都会和这种“信息该怎样被放行或抑制”有关。

## 不同激活函数的差别，本质上在于它们如何处理中间响应

初学阶段不需要死背很多激活函数家谱。
更重要的是理解它们在概念上如何不同。

`Sigmoid` 和 `Tanh` 较早出现，它们会把输出压进有限区间。
这让模型获得平滑非线性，但也更容易在极端区间出现饱和，导致梯度变弱。

`ReLU` 的重要性在于它非常直接。
它会把负值截断为零，把正值原样放行。
这让模型获得一种简单而强力的分段线性门控：

- 负响应可以被完全关闭
- 正响应可以近似不受阻碍地继续往前传

`GELU` 则更柔和。
它不是简单粗暴地硬截断，而是让小响应按幅度和符号更平滑地被调节。
这也是为什么很多现代语言模型更偏爱它或相关变体。

如果从结构功能上压缩来看，这些激活函数真正的区别不是“名字不同”。
而在于：

> 它们怎样决定哪些中间响应该被强硬关闭，哪些该被柔和保留，哪些该被更平滑地缩放。

所以激活函数不是“调味料”。
它直接影响表示如何流动、梯度如何传播、模型如何分段地响应输入。

## 什么叫“表示”，以及为什么它不是“中间结果”的高级说法

现在可以回到本章最核心的词了：表示。

表示不是一个为了让神经网络显得深奥才使用的词。
它真正指的是：

> 在当前层里，模型用什么坐标系、什么特征组织方式、什么内部描述格式来表达输入对象。

这和“中间结果”并不完全一样。

“中间结果”只说明：

> 这是一段计算过程中的临时输出。

而“表示”强调的是：

> 这段输出并不是任意数字，它是一种带结构意义的内部描述。

同一个句子进入模型以后，刚开始可能只是 token id。
再往后可能变成 embedding。
再往后变成更丰富的上下文表示。

这些都不是“顺手算出来的一串中间数”。
它们分别对应模型在不同阶段对同一个对象的不同内部说法。

所以表示学习真正学的，不只是“权重应该是多少”。
它在更深的层面上学的是：

> 怎样把原始对象逐步翻译成对当前任务更友好的内部描述。

## 表示为什么常常是分布式的，而不是“一维一义”的

初学者很容易对表示产生一种过度朴素的期待：

> 这一维是不是就代表某个固定语义？
> 那一维是不是就代表另一个固定特征？

现实里，有些局部维度确实可能更偏向某类模式，但现代神经网络里的表示更常见的是分布式编码。

这意味着：

- 一个概念往往由很多维共同承担
- 一个维也可能同时参与很多概念

这种方式看起来不够直观，但它有很强的表达优势。

因为现实世界里的模式本来就很少是“一个概念对一个维度”这么干净。
分布式表示允许模型：

- 更灵活地组合模式
- 在不同任务间共享统计结构
- 用较少的硬边界去表达更复杂的关系

所以隐藏表示之所以强，不在于每个维都很容易被人类解释。
而在于：

> 整个向量空间一起，能够表达比单维语义标签更丰富的结构。

## 深度真正增加的，不只是层数，而是连续改写表示的机会

现在你已经可以把“深层网络为什么更有意义”说得更准确了。

它不是简单地“参数更多，所以更强”。
更关键的地方在于：

> 深度给了模型多次连续重写表示的机会。

第一层也许只学会很局部的模式。
第二层也许开始组合这些局部模式。
第三层也许进一步把它们整理成更贴近任务决策的中间对象。

这条链越往后，模型看到的就越不是原始输入，而是经过多次内部翻译之后的新对象。

这也是为什么深层网络在很多任务上比浅层方法强得多。
因为很多复杂关系不是“一步看穿”的。
它们需要多轮表示改写，才能慢慢从原始输入里被抽出来。

所以深度真正增加的，不只是计算长度。
它增加的是：

> 让模型逐层把对象写成“越来越适合任务”的内部语言的机会。

## 这和语言模型有什么直接关系

如果你现在问：

> 这些关于线性层、激活函数和表示空间的讨论，和语言模型到底有什么直接关系？

答案是：关系非常直接。

语言模型里你不断会看到：

- token embedding
- hidden state
- residual stream
- attention output projection
- MLP / FFN
- logits head

这些东西看起来名字不同，但它们都围绕同一件事展开：

> 模型正在不断把当前 token 序列的内部表示改写成下一阶段更有用的形式。

embedding 是一种初始表示。
attention 是一种按上下文重组表示的机制。
前馈层又会对当前位置表示做进一步的非线性改写。
最后的 logits 头，则把最终表示接到输出候选空间。

所以你后面看到 Transformer 时，千万不要把它学成：

- 这里一块注意力
- 那里一块前馈
- 再加几个残差

更稳定的看法是：

> 整台模型在不断通过线性变换和非线性门控，把 token 序列重写成越来越适合下一 token 预测的内部表示。

一旦这个视角站稳，后面的很多结构就都不会显得零碎。

## 这一章真正想留下的主线

如果把整章压缩成最核心的一条链，可以写成：

> 线性层的作用不是“因为连得多所以强”，而是通过可学习权重重新定义读取方向和表示空间；单个神经元可以被看成一个模式探测器，一整层则是在并行提出很多可学习问题；偏置补上了默认参考面；但纯线性堆叠会塌缩成一次整体线性变换，因此真正让深层网络获得新表达能力的是非线性；激活函数于是承担起门控和分段响应的角色；而所谓表示学习，指的正是模型通过多轮线性重组和非线性筛选，把原始对象逐步改写成更适合任务的新内部语言。

这条主线一旦稳住，后面你再遇到：

- MLP
- FFN
- hidden state
- residual stream
- projection

这些词时，就不会只是机械地把它们当层名。
你会知道它们都在服务同一件事：

> 持续改写表示。

## 读完本章后，你应该能稳定回答什么

如果这一章真正读稳了，你应该能够不用背诵术语，而是用自己的话稳定回答下面这些问题：

- 线性层到底在“读”输入里的什么
- 为什么单个输出神经元可以被理解成一个模式探测器
- 为什么一整层可以被看成并行提出很多可学习问题
- 偏置到底在补什么
- 为什么只堆线性层不会真正增加表达能力
- 激活函数为什么不是可有可无的小修饰
- 什么叫表示，为什么它不只是“中间结果”的另一种叫法
- 为什么深度真正增加的是连续改写表示的机会

只要这些问题能够稳定答出来，这一章就已经完成了最重要的任务：

> 它让“神经网络是一台表示学习系统”不再只是一句概括，而变成了你能沿着线性层、非线性和内部表示一路解释下去的具体结构事实。
