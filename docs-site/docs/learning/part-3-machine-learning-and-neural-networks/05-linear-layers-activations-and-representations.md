# 01. 线性层、激活函数与表示空间

这一章是很多读者第一次真正走进神经网络内部的地方。

到这里为止，你已经知道：

- 一个学习问题至少要有样本、目标、预测和损失。
- 模型可以被看成带参数的函数。
- 线性模型为什么是透明起点。
- 神经网络为什么会通过隐藏层和非线性突破线性边界。

但如果要继续往前走，你迟早会反复遇到一组不断出现的词：

- 线性层
- 激活函数
- 隐藏层
- 表示
- projection
- hidden state

你会在最简单的 MLP 里看到它们。
你会在分类器里看到它们。
你会在 Transformer 里一次又一次看到它们。

可仅仅认识这些名字，并不等于你真的知道神经网络在做什么。

很多初学者会卡在一种非常典型的中间状态：

- 知道 `Linear` 是一个常用层。
- 知道 `ReLU`、`GELU` 是激活函数。
- 知道网络会一层层往前算。
- 也知道最后会 `backward`。

可如果继续追问：

- 线性层到底在读输入里的什么？
- 激活函数为什么不是可有可无的小修饰？
- 为什么神经网络总在谈“表示”？
- 隐藏层到底在保存什么？
- 为什么同一个对象经过很多层后，会越来越适合当前任务？

很多人的解释能力就会开始失稳。

这说明问题不在于你没见过公式，而在于你还没有把这些公式看成一条连续的表示加工链。

这一章要解决的正是这个断裂。

更准确地说，本章要回答五个紧密咬合的问题：

1. 线性层到底在对输入做什么。
2. 激活函数到底在补什么结构能力。
3. 什么叫表示，为什么现代模型本质上都在学习表示。
4. 为什么“投影到另一个空间”会在模型里反复出现。
5. 为什么同样的思路会一路延伸到 attention 和 Transformer。

如果这几件事真正站稳，后面你再去看：

- embedding
- hidden state
- Q、K、V projection
- FFN
- residual stream
- logits

你看到的就不再是一堆独立零件，而是一条持续改写内部表示的计算链。

## 神经网络首先不是“很多层”，而是一台表示改写机器

很多人对神经网络最粗糙的理解是：

- 输入一些数字。
- 中间经过若干层。
- 输出一个结果。

这个说法不能说错，但它太弱了。

更有力量的说法是：

> 神经网络首先是一台不断改写表示的机器。

这里的“表示”不是一个故作高深的术语。它真正指的是：

> 模型此刻用什么方式组织、压缩、突出和重写输入信息，使它更适合后续任务判断。

这件事非常重要，因为它会直接改变你理解网络结构的方式。

如果你把神经网络看成一组 API 的堆叠，那么你看到的往往只是：

- 这里乘一个矩阵。
- 那里加一个偏置。
- 中间过一个激活。
- 最后吐出一串数。

这种观察不能说错，但它几乎不会留下长期直觉。

如果你把神经网络看成表示改写系统，那么你看到的会是另一条主线：

- 这一层想从当前对象里读出什么模式。
- 这一层把哪些变化保留下来。
- 这一层把哪些变化压低或忽略。
- 这一层输出的新对象，为什么会更适合下一层继续处理。

后一种视角，才是真正稳定的视角。

因为后面无论你再看到 attention、残差流、前馈网络还是隐藏状态，归根到底都会回到同一件事上：

> 模型不是只在“做更多计算”，而是在不断把当前对象改写成更适合任务的新表示。

## 线性层的本质不是“连得多”，而是“重新定义读取方向”

很多入门材料介绍线性层时，会说：

> 它把所有输入神经元和所有输出神经元都连起来。

这句话从实现角度不算错，但它很容易把理解带偏，因为它会让初学者停留在一种很浅的印象里：

- 这层很强。
- 因为它连接很多。

更接近本质的说法应该是：

> 线性层在学习一组可调整的读取方向和重组规则。

也就是说，它的重要性不在于“连接很多”，而在于：

- 它能沿很多不同方向读输入。
- 它能把读出来的结果重新组织成新的坐标系。
- 它能为下一步计算定义一个更合适的表示空间。

这是理解线性层最关键的入口。

神经网络不是靠“连接感”取胜的，而是靠“表示改写能力”取胜的。线性层，就是最基础的表示改写器。

## 从单个输出维重新理解线性层，会比直接背矩阵式更稳

我们先不要急着看一整层，先回到最简单的情况。

假设这一层只输出一个标量：

\[
z=w^\top x+b
\]

这里的 \(w\) 可以看成一组权重。你也可以把它理解成：

> 这一维输出拿着一张可学习的问题模板，去问输入：“你在这个方向上的响应有多强？”

这句话非常重要，因为它让你看到：

- 输出维度不是凭空出现的。
- 每个输出维都在对应某种读取方向。
- 权重向量 \(w\) 定义了“怎么读”。
- 偏置 \(b\) 定义了“默认基线在哪”。

如果某个输出维很大，往往意味着：

> 输入在这组权重所代表的模式方向上，响应得很强。

所以单个输出神经元最自然的理解方式，不是“一次乘加”而已，而更像是：

- 一个模式探测器
- 一个方向响应器
- 一个可学习的问题

一旦这样理解，很多后面的概念都会变得顺畅。例如：

- 为什么不同输出维会学出不同职责。
- 为什么一层可以同时并行读很多模式。
- 为什么某些输出维会和某种局部结构特别相关。

## 从单个输出维到一整层，本质上是在并行提出很多可学习问题

当输出不止一个维度时，你就得到一整层：

\[
y=Wx+b
\]

其中：

- \(x \in \mathbb{R}^{d_{in}}\)
- \(W \in \mathbb{R}^{d_{out}\times d_{in}}\)
- \(y \in \mathbb{R}^{d_{out}}\)

你当然可以把它读成一个矩阵乘法，但更稳定的理解方式是：

> 这一层正在并行发出 \(d_{out}\) 个不同的可学习提问，然后把输入沿这些提问方向重新投影。

每一行权重都在代表一种读取模式。整层一起工作时，模型不是只得到一个判断，而是得到一组新的中间描述。

于是，线性层不再只是“把输入变成输出”。它更像是在做：

> 把当前对象翻译进另一个表示空间。

这句话非常关键，因为它解释了为什么同样是线性层：

- 有时它负责降维。
- 有时它负责升维。
- 有时它负责把同一个对象重新写到另一个空间里。
- 有时它只是为下一层准备一个更好加工的中间表示。

所以线性层本质上不只是“算分”。它是在“换一种说法来描述当前对象”。

## 偏置不是边角项，它在决定默认参考面

很多初学者学线性层时，会把偏置看成一句附带说明：

> 就是再加一个 \(b\)。

这会严重低估偏置的作用。

如果没有偏置，线性变换只能围绕原点组织表达。这意味着模型对很多模式的响应会被迫受到“必须经过原点”的限制。

引入偏置之后，模型等于获得了一个更灵活的参考面。它不必总从原点开始判断“这个方向有多强”，而可以把默认基线挪到更合理的位置。

如果用最朴素的话说，偏置补的是：

> 即使所有输入维都接近零，输出也不一定应该被迫认为“这里就是绝对零响应”。

所以偏置让模型学到的，不只是“不同方向如何加权”，还包括：

> 从哪条基线开始判断才更合理。

## 为什么“投影”这个词会在模型里反复出现

你会在很多地方看到 `projection` 这个词：

- embedding projection
- Q projection
- K projection
- V projection
- output projection

如果只是把它们都翻译成“线性层”，理解仍然偏浅。更好的理解是：

> 投影是在说：把当前对象从一种表示坐标系，写到另一种更适合当前子任务的坐标系里。

这件事之所以会反复出现，是因为同一个对象在不同任务环节里，需要被不同方式读取。

例如：

- 某个空间更适合做匹配。
- 某个空间更适合做内容传递。
- 某个空间更适合做最终分类。

于是模型会一次次使用线性层，把对象投到不同空间里。这样看，投影不是重复劳动，而是：

> 根据当前任务需要，重新选择看待这个对象的坐标系统。

## 只有线性层为什么不够

讲到这里，真正的分界线就该出现了。

很多初学者都会自然地想：

> 那我多堆几层线性层，不就更强了吗？

这是一个非常自然、也非常值得认真对待的误解。

如果你把多层线性层直接串起来，中间完全不插入非线性，那么整个系统仍然可以合并成一次更大的线性变换。

这意味着：

- 表面上层数变多了。
- 参数量可能也更大了。
- 计算图看起来更深了。

但表达能力并没有因此跨出线性系统的边界。

所以神经网络的力量，不来自“线性层堆得够多”，而来自：

> 在线性重组之间插入非线性，让表示改写不再塌缩成一次统一线性变换。

## 激活函数到底在补什么

激活函数最常见的误解是：

> 它是一个让网络“稍微复杂一点”的小修饰。

这不对。

激活函数真正补的是：

> 让模型在不同输入区域里可以采取不同的局部响应规则，从而打破单一线性系统的表达上限。

也就是说，线性层负责把输入搬运到某个更适合操作的坐标空间，而激活函数负责让这次搬运之后的对象，不再只能被单一线性关系统治。

于是模型开始获得：

- 分段响应能力
- 局部弯折能力
- 更复杂边界表达能力
- 多层复合之后持续增长的表示能力

如果没有激活函数，隐藏层就只是在做“可合并的中转站”。有了激活函数，隐藏层才真正开始承担表示改写的职责。

## 为什么激活函数通常紧跟在线性层后面

现在你就能更自然地理解一个非常常见的结构：

\[
\text{Linear} \rightarrow \text{Activation}
\]

这不是因为框架作者恰好喜欢这么写，而是因为这套顺序刚好在做两件互补的事：

1. 先用线性层把当前表示投影到一个更适合处理的空间。
2. 再用激活函数把这个空间里的响应转成更有表达力的局部结构。

如果只有第一步，没有第二步，很多层叠起来仍会塌缩成一个大线性映射。如果只有第二步，没有第一步，系统又缺乏足够灵活的可训练重组能力。

所以现代网络里反复出现的，不是某一个具体激活函数，而是一种更一般的结构思想：

> 在线性重组和非线性改写之间循环，把简单映射堆叠成复杂函数。

## 什么叫表示空间，不要把它理解成神秘黑盒

“表示空间”这个词经常把初学者吓到，好像一说出来就意味着某种高深数学对象。

其实它最朴素的意思就是：

> 模型当前用来组织对象的一套坐标系和特征语法。

例如，同样一个输入 token：

- 在原始离散 id 空间里，它只是一个整数标签。
- 在 embedding 空间里，它变成一个稠密向量。
- 在更深层的隐藏状态空间里，它又变成了融合上下文之后的新表示。

这些不是同一个东西“换了个名字”，而是模型用不同空间去重写和组织对象的不同阶段。

所以当我们说“这一层把对象送进另一个表示空间”时，并不是在说对象本体变成了别的东西，而是在说：

> 模型换了一套更适合当前任务的内部组织方式。

## 为什么表示比原始输入更重要

这一点对神经网络理解极其关键。

原始输入当然重要，但现代模型真正的工作重心，往往不在原始输入本身，而在：

> 它怎样一步步把原始输入改写成更有用的内部表示。

原因很简单。

原始输入往往是任务不友好的：

- 文本最初只是离散符号。
- 图像最初只是像素格子。
- 语音最初只是波形序列。

这些原始对象对最终任务并不总是直接友好。模型之所以有用，是因为它能把这些原始对象变换成：

- 更容易分离的
- 更容易匹配的
- 更容易压缩的
- 更容易综合上下文的

内部表示。

所以神经网络的主战场常常不在输入端，也不只在输出端，而在中间层层推进的表示空间里。

## 隐藏状态到底是什么

现在可以顺手把一个经常出现的词说清楚：hidden state。

很多人会把隐藏状态听成一种神秘内存，仿佛它是一块模型偷偷保存的秘密区域。

更准确的理解应该是：

> 隐藏状态就是模型在当前阶段对输入对象的内部表示。

它之所以“隐藏”，不是因为它神秘，而是因为：

- 它不是直接给用户看的输出。
- 它也不是外部世界天然提供的标签。
- 它是模型自己在内部加工出来、供后续层继续使用的中间对象。

理解这一点之后，你就会更容易看懂：

- 为什么不同层的 hidden state 会有不同语义侧重。
- 为什么 attention 处理的不是原始 token，而是隐藏状态。
- 为什么 residual stream 会贯穿整个网络。

因为模型真正传递的，不是“词本身”，而是不断被重写的内部表示。

## 为什么可以说神经网络本质上是在学习表示

到这里，终于可以把“表示学习”这个大词落地了。

如果一个模型只是学会：

> 在固定特征上做最终分类或回归，

那它更像是在学习一个判断规则。

如果一个模型还能学会：

> 什么样的中间特征表达，更有助于后续判断，

那它就在做表示学习。

现代神经网络的强大，很大程度上就在这里。它不再只学最后的判别器，还在学：

- 哪些模式值得突出
- 哪些局部结构值得压缩
- 哪些组合关系值得保留
- 怎样让原始对象进入一个对任务更友好的空间

所以“神经网络在学表示”不是一种文学化说法，而是在精确描述它们的核心能力来源。

## Transformer 里为什么仍然到处都是线性层和激活函数

有些读者学到 Transformer 时会产生一种错觉：

> 既然 attention 才是主角，那线性层和激活函数大概只是配角。

这是不对的。

Transformer 当然以 attention 著称，但它并没有抛弃这条更古老的主线。恰恰相反，它把这条主线嵌进了更复杂的序列结构里。

例如：

- Q、K、V 都是通过线性投影得到的。
- attention 输出后还会经过线性整合。
- block 里的前馈网络本质上仍是线性层加非线性。
- 最终 LM head 也仍然是线性映射。

这说明：

> 即使在最现代的语言模型里，线性重组和非线性改写仍然是表示加工的底层骨架。

attention 并没有取代它们，而是把“跨位置读取”这件事插入到了这条骨架中间。

## 初学者在这里最容易犯的几个误解

第一个误解是：线性层就是“全连接很多”，所以它厉害是因为参数多。

错。参数多只是表面现象，更本质的是它在学习读取方向和表示重组规则。

第二个误解是：激活函数只是小修饰，有没有差别不大。

错。激活函数承担的是打破单一线性系统上限的职责，没有它，多层线性仍会塌缩。

第三个误解是：表示空间是一个抽象玄学词。

错。表示空间只是在说模型当前怎样组织对象、采用什么内部坐标系。

第四个误解是：隐藏状态是某种神秘记忆块。

错。隐藏状态本质上就是当前阶段的中间表示。

第五个误解是：Transformer 已经主要靠 attention，所以线性层和激活函数的重要性下降了。

错。它们仍然是表示改写的底层骨架，attention 只是把跨位置读取能力插入了这条骨架。

## 这一章真正要记住的核心句子

如果只能记住一句话，请记住这一句：

> 线性层负责把当前对象投影到新的读取方向和表示空间里，激活函数负责打破单一线性系统的表达上限，而整台神经网络的真正工作，就是在这一轮轮线性重组与非线性改写中逐步学出更适合任务的内部表示。

## 读完这一章之后，你应该能稳定回答这些问题

- 线性层到底在“读”输入里的什么？
- 为什么说一整层像是在并行提出很多可学习问题？
- 偏置到底补了什么？
- 为什么“投影到另一个空间”会在模型里反复出现？
- 激活函数到底在补什么能力？
- 什么叫表示空间和隐藏状态？
- 为什么可以说神经网络本质上是在学习表示？

## 如果现在只能先养成一个观察习惯

请先养成这个习惯：

> 每看到一个层，不要只问“它叫什么”，而要先问“它把当前对象重新写进了什么空间，这个空间为什么更适合下一步处理”。

只要这个习惯稳定下来，后面的模型结构会容易理解很多。

## 小结

这一章把几组看似分散的词重新接回了同一条主线：

- 线性层
- 偏置
- 激活函数
- 投影
- 表示空间
- 隐藏状态

它们共同回答的是同一件事：

神经网络为什么不是一堆 API 的顺序调用，而是一台持续改写内部表示的机器。

后面当你进入 attention、FFN、residual stream 和 logits 时，请始终带着这个视角。那样你看到的就不再是不断增加的新组件，而是同一个表示学习思想在更复杂结构里的持续展开。
