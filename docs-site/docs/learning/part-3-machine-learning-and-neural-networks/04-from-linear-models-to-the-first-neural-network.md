# 04. 从线性模型到第一个神经网络

这一章处在整套学习路径里一个非常关键的位置。

前面你已经知道：

- 一个学习问题由样本、特征、目标、预测和损失构成
- 模型可以被看成带参数的函数
- 非线性为什么在抽象层面重要

但到这里还差一个非常关键的过渡没有真正走完：

> 神经网络究竟是从什么起点一步步长出来的？

如果这件事不讲清楚，后面读到：

- hidden size
- MLP
- FFN
- 激活函数
- projection

这些词时，感觉就会像“新的零件不断出现”，而不是“沿着一条连续历史和结构逻辑自然长出来的系统”。

所以这一章不从“神经网络很强”开始，而是从一个更朴素也更根本的问题开始：

> 如果我们只允许模型做一次全局加权求和，会发生什么？它在哪些地方已经够用，又在哪些地方必然不够？

## 为什么要先从线性模型出发

很多初学者会有一种天然冲动：

> 既然最终目标是学大语言模型，那我是不是可以直接跳到 Transformer？

不应该。

因为现代大模型并不是扔掉了线性模型，而是在更大结构里反复重用了线性模型时代留下的核心原理与部件。

如果你跳过线性模型，后面会出现三类持续性困惑：

- 你知道某层在做线性投影，却不知道“投影到底在补什么”
- 你知道多层结构更强，却不知道“强在哪里”
- 你知道非线性很重要，却只能机械背结论，讲不清没有它会怎样

线性模型的重要性不在于它是“历史课”，而在于它是：

> 理解可学习参数、全局规则、决策边界、表示能力和结构限制的最透明起点。

## 最朴素的可学习模型：加权求和

设一个样本的输入特征写成向量：

\[
x = [x_1, x_2, \dots, x_d]
\]

最朴素的模型会做下面这件事：

\[
z = w_1x_1 + w_2x_2 + \dots + w_dx_d + b
\]

更紧凑地写成：

\[
z = Wx + b
\]

这个式子看起来极其简单，但它已经包含了训练系统最核心的一层骨架：

- `x` 是输入对象
- `W` 和 `b` 是可学习参数
- `z` 是模型根据当前参数给出的分数或预测

如果你暂时把所有更复杂结构都删掉，只保留这一层，你会发现：

> 机器学习最早、最清楚的一批模型，本质上就是在学习“输入特征应该怎样被统一加权组合”的规则。

## 线性模型到底在学什么

从结构上看，线性模型在学的是：

> 一套全局一致的特征组合规则。

假设有两个样本：

```text
样本 A: x = [1.0, 2.0, 0.1]
样本 B: x = [0.8, 1.5, 0.9]
```

模型不会为样本 A 和样本 B 分别重新发明判断方式。
它使用的是同一组参数：

```text
w = [w1, w2, w3]
```

这意味着模型在学习：

- 哪些特征更重要
- 哪些特征作用较弱
- 它们怎样被统一组合成一个分数

这种“统一规则”视角非常重要，因为它解释了为什么线性模型更像是在学：

> 一个全局有效的评分机制

而不是：

> 为每个样本背一份答案。

## 为什么线性模型值得认真对待

有些读者会把线性模型误解成：

> 神经网络出现之前的简陋玩具。

这不准确。

线性模型长期没有消失，原因非常实际：

- 它结构清楚
- 参数相对容易解释
- 训练稳定
- 数据量不大时也常常能工作
- 作为基线模型非常有价值

更重要的是，它是最容易让你看清“参数到底在做什么”的模型。

在深层网络里，一个参数的影响往往要经过多层传播和耦合才表现出来。
但在线性模型里，你可以相对直观地理解：

- 权重大，说明该特征影响更强
- 权重为正，说明它把输出往某一方向推
- 权重为负，说明它把输出往相反方向推
- 偏置 `b` 则在整体上平移决策阈值

所以线性模型的价值不只是“够简单”，更在于：

> 它让“从输入到参数，再到输出”的关系第一次变得足够透明。

## 用几何视角看线性模型：它在画超平面

在线性分类里，一个非常核心的概念是决策边界。

假设模型根据分数 `z` 来做判断：

- `z > 0` 判为一类
- `z < 0` 判为另一类

那么边界就是：

\[
Wx + b = 0
\]

这个边界在不同维度里有不同外观：

- 在二维里是一条直线
- 在三维里是一个平面
- 在更高维里则是超平面

这句话的含义非常大：

> 线性模型本质上就是在尝试用一个超平面，把特征空间切成若干区域。

如果这个任务刚好能够被一条直线、一个平面或者一个更高维超平面分开，线性模型就会显得非常自然。

如果问题本身比这更复杂，线性模型就会开始撞墙。

## 权重和边界方向是什么关系

在表达式：

\[
Wx + b = 0
\]

里，`W` 不只是参数表，它还决定了边界的朝向。

直觉上你可以把 `W` 理解成：

> 决策边界的法向量，也就是垂直于边界的方向。

这意味着：

- 改变 `W`，会改变边界的方向
- 改变 `b`，主要会改变边界的位置

这会帮助你更好地理解训练到底在做什么：

> 训练不是在“凭空神奇分类”，而是在不断旋转、平移和重定向这条决策边界，让它更适合当前数据。

## 线性可分为什么重要

如果存在某个超平面，可以把不同类别样本干净地区分开，我们就说这个数据集是线性可分的。

例如在二维平面里：

- 红点都集中在左上
- 蓝点都集中在右下

如果一条直线能把它们完全分开，那么这个问题就是线性可分的。

在线性可分的问题上，线性模型往往非常自然，因为它的结构目标本来就是在找这样的边界。

这也是为什么早期很多分类理论都围绕“是否线性可分”展开。
因为一旦线性可分成立，问题会突然变得：

- 结构简单
- 解释清楚
- 训练相对直接

## 为什么线性可分是一个很强但很脆弱的假设

线性可分之所以强，是因为它把问题压缩得很干净。

但它也很脆弱，因为现实中大量规律并不满足：

> 一个超平面就能把所有情况干净分开。

现实问题更常见的情况是：

- 特征之间有交互
- 不同局部区域有不同规则
- 决策边界是弯曲的
- 某种标签取决于组合关系而不是单一方向

此时问题不再是“线还没画对”，而是：

> 你手里只有一把直尺，但问题需要的其实是更复杂的空间改写能力。

这就是线性模型会撞墙的地方。

## XOR 为什么这么经典

XOR 之所以被反复拿来讲，不是因为现实数据都长得像 XOR，而是因为它极其干净地暴露了线性模型的结构边界。

你可以把 XOR 关系理解为：

- 两个输入相同，输出为 `0`
- 两个输入不同，输出为 `1`

如果把这四种情况画在二维平面上，你会发现：

- 需要被判成 `1` 的点对角分布
- 需要被判成 `0` 的点也对角分布

此时不存在一条直线能把它们彻底分开。

这说明问题不在于：

- 权重还没调好

而在于：

- 结构本身没有表达这种关系的能力

这类例子极其重要，因为它提醒你：

> 有些失败不是训练没跑够，而是模型家族本身不够表达这个任务。

## 线性模型的真正限制到底在哪里

讲到这里，可以更系统地说出线性模型的问题了。

第一，它只能表达线性边界。

第二，它没有中间层来逐步改写表示。

第三，它很难自然表达复杂的特征交互。

第四，它严重依赖输入特征已经足够好。

如果原始输入本身就已经把任务结构暴露得很清楚，线性模型可能工作得不错。
但如果任务需要：

- 多层抽象
- 局部组合
- 非线性交互
- 不同区域采用不同规则

它就会迅速露出上限。

所以线性模型最重要的历史意义，不只是它做成了什么，更是：

> 它清楚地暴露了下一代模型必须补什么。

## 手工特征工程在修补什么

在神经网络广泛流行之前，人们并不是完全无计可施。
一个自然的补救思路是：

> 既然线性模型不会自己造复杂表示，那就由人提前把更有用的特征造出来。

例如：

- 增加平方项
- 增加交叉项
- 设计统计摘要
- 提取 n-gram
- 构造人工规则分数

这就是手工特征工程。

它本质上是在做一件事：

> 把原本线性模型表达不了的关系，提前编码进输入表示里。

这种方法在很多传统机器学习任务里非常有效，也极其重要。
但它也暴露了一个更深的问题：

> 如果每个任务都要靠人先猜出哪些高阶组合重要，那么模型本身的学习能力仍然非常有限。

## 为什么手工特征工程最终还是不够

手工特征工程并没有错。
它只是有天然上限。

第一，它依赖人类事先猜到什么特征重要。

第二，任务一复杂，特征组合会爆炸。

第三，它缺乏层级表示能力。

第四，文本、图像、音频这类高维原始输入几乎不适合完全靠手工设计特征。

所以问题开始转向另一种想法：

> 我们能不能让模型自己学会中间表示，而不是总让人先把表示写好？

这正是神经网络真正接管舞台的地方。

## 第一个关键突破：隐藏层

如果只看线性模型，输入会被直接映到输出。

这意味着整个任务难度都压在这一跳上：

```text
输入 -> 输出
```

而一旦引入隐藏层，结构就变成：

```text
输入 -> 中间表示 -> 输出
```

这件事的意义非常大。

因为它意味着模型不必再把原始输入直接拿去做最终判断，而是可以先把输入重写成某种更适合任务的内部描述，再在这个内部描述上做后续判断。

换句话说，隐藏层带来的不是“多了一层而已”，而是：

> 模型第一次获得了自己构造中间表示的能力。

这就是从传统线性模型迈向神经网络的分界点之一。

## 但只有隐藏层还不够

这里一定要防止一个常见误解：

> 那我把几层线性层堆起来，不就有隐藏层了吗？

不够。

如果每一层都只是线性变换，那么多层线性层复合起来，整体上仍然只是一个更大的线性变换。

也就是说：

- 表面上层数变多了
- 本质上表达家族没变

这就是为什么非线性会成为真正的分界线。

## 非线性为什么会成为分界线

一旦在线性层之间插入激活函数，事情就发生了本质变化。

模型不再只是做：

- 统一拉伸
- 统一旋转
- 统一平移

它开始能够让不同区域经历不同的变换。

这意味着模型获得了：

- 更复杂的边界形状
- 更灵活的局部规则
- 更强的特征重组能力

所以“神经网络为什么比线性模型强”最不应该背成：

- 因为它参数更多

更稳的说法是：

> 因为它不仅能学习权重，还能通过隐藏层和非线性持续改写表示空间。

## 神经网络到底是在“画弯曲边界”还是“改写表示空间”

这两种说法都常见，也都各有价值。

如果你站在分类边界视角看，神经网络好像是在学更复杂、更弯曲的决策边界。

如果你站在表示学习视角看，神经网络更像是在做另一件事：

> 逐层把原始输入改写到一个更适合任务的内部空间里，让原本难分的问题在后续空间里变得更容易分。

从更长远的学习角度看，第二种说法更有力量。

因为它能自然解释后面几乎所有现代模型现象：

- 为什么隐藏层重要
- 为什么深度重要
- 为什么 embedding 重要
- 为什么 attention 也可以理解成一种信息重组机制

所以到了今天，更推荐你把神经网络理解成：

> 一台持续重写表示空间的机器。

而不是只理解成“会画更复杂边界的分类器”。

## 第一个前馈神经网络最该怎样理解

如果把最简单的前馈神经网络写成一条链，可以想成：

```text
x
-> 线性变换
-> 非线性激活
-> 再做线性变换
-> 输出
```

这条链最重要的地方不在于它看起来更长，而在于三件事发生了。

第一，原始输入不再是最终语义层。
模型允许自己先构造中间层。

第二，输出层不再独自承担全部难度。
难点被拆分到多层表示改写过程中。

第三，学习从“调一个边界”变成“逐层塑造表示”。

这就是神经网络真正比线性模型多出来的世界。

## 宽度和深度分别在改变什么

理解了神经网络的基本动机后，宽度和深度的意义也就更容易把握了。

### 宽度在增加什么

更宽的层意味着同一层里可以并行表示更多方向、更多模式、更多局部探测器。

### 深度在增加什么

更深的网络意味着表示可以被反复改写，多层抽象可以逐级堆叠。

所以不要把宽度和深度简单理解成：

- 参数更多了

更好的说法是：

- 宽度增加同层表达容量
- 深度增加多阶段表示变换能力

这套思维方式后面会一路延伸到：

- Transformer block 的堆叠
- hidden size 的选择
- FFN 宽度的作用

## 为什么现代大模型仍然深受这条历史路径影响

到了 LLM 时代，很多人会以为：

- 线性模型是远古时期
- 神经网络入门只是过渡
- 现在真正重要的是 attention

这会让你错过一个关键事实：

> 现代大模型并没有抛弃这条历史路径，而是在更大规模上把它们重新组织起来。

例如：

- embedding 是输入表示映射
- attention 中的 `Q/K/V` 投影仍然是线性层
- FFN 本质上仍然是带非线性的前馈网络
- 最终 logits 层仍然是把隐藏表示映到词表空间

也就是说，今天的大模型之所以复杂，不是因为它完全换了一套物理世界。
而是因为：

> 线性变换、非线性和表示学习这些早期思想，被放进了更深、更宽、更适合序列建模的结构里。

如果你不先理解从线性模型到第一个神经网络这条路，后面看到的大模型结构就会只剩模块名，而没有来路。

## 读完本章后，你应该能稳定回答什么

如果这一章真正起作用了，你应该能够稳定解释下面这些问题：

- 为什么线性模型是理解神经网络的透明起点
- 线性模型在学什么全局规则
- 决策边界和超平面之间是什么关系
- 为什么有些失败是结构能力不够，而不是训练不够
- 手工特征工程在修补什么，又为什么最终不够
- 隐藏层到底带来了什么
- 为什么非线性是分界线，而不是装饰件
- 为什么神经网络更适合理解成“表示空间改写机器”

如果这些问题还答不稳，后面读到 MLP、FFN、projection、activation 时，你仍然会觉得自己在看零件表。

## 小结

这章最想留下的主句可以浓缩成这样：

> 神经网络不是凭空多出来的一堆术语，而是在线性模型表达上限暴露之后，为了获得中间表示和非线性空间改写能力而自然长出来的下一代结构。

再落回更具体的训练视角，这句话还可以进一步写成：

> 从线性模型到神经网络，真正新增的不是“更多参数”这么简单，而是模型终于能不只调一个全局边界，而是逐层学习怎样把输入改写成更适合任务的表示。

只要这个认识站稳，后面的：

- 线性层
- 激活函数
- 多层感知机
- Transformer 里的 FFN

就都会重新回到同一条因果链上：

> 它们都在回答同一个问题，模型怎样从原始输入一路长出更有表达力的内部表示。
