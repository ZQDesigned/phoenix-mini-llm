# Part 6. 推理、评估与调试

很多学习项目都会卡在这里：

- 模型能跑
- loss 也在变
- 但你不知道它到底是不是在正常学习

这一分册的职责，就是把“模型训练后到底怎样使用与判断”讲清楚。

它最终会覆盖：

- 自回归生成的 prefill 和 decode
- greedy、temperature、top-k、top-p 的关系
- KV cache 为什么属于现代推理基础知识
- 困惑度和样例评估分别在观察什么
- 极小数据过拟合测试为什么是链路验证利器
- 常见故障应该怎样分类、复现和定位

一个项目是否真正让你成长，最后往往不取决于“它是不是跑起来了”，而取决于：

> 当它行为不对时，你是否知道如何判断、缩小范围并修复。

这正是这一分册要培养的能力。
