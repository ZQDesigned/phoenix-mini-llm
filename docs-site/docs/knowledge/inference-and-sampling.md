# 7. 推理与采样

## 生成不是只做 argmax

如果每一步都取最大概率 token，输出往往会变得单一和重复。所以项目同时支持：

- temperature
- top-k
- top-p

## 三个概念怎么区分

### temperature

控制分布“平”还是“尖”。

### top-k

只保留概率最高的 `k` 个候选。

### top-p

按累计概率截断候选集，只保留“概率质量够了”的那部分 token。

## 什么时候看起来像“模型坏了”

小模型、短训练、低步数下，生成文本很容易：

- 语法断裂
- 重复
- 出现怪符号

这不一定表示代码错了，也可能只是：

- tokenizer 词表太小
- 训练步数太少
- 数据子集太小

要结合验证 loss 和脚本链路一起判断。
