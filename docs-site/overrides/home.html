项目聚焦

这套项目关注什么

  • 一个适合学习的小型 decoder-only 语言模型
  • 从语料、Tokenizer、模型、训练到生成的完整链路
  • 在有限显存约束下仍然可解释、可训练、可复刻的实现

项目边界

这套项目不追求什么

  • 不把重点放在超大参数规模或营销式“大模型感”包装
  • 不把文档写成只会复制命令的部署说明
  • 不把工程脚手架包装成无法解释的黑箱

学完后你应该会

不是把项目跑起来，而是能解释、能复做、能排错、能继续扩展。

解释机制

你能清楚解释 token、embedding、cross-entropy、attention、KV cache 在同一台模型里分别扮演什么角色。

独立落地

你能从空目录开始配置 `uv`、组织 Python 包、准备语料和 tokenizer，再把训练与推理链路完整接起来。

跨平台推进

你能在 macOS 上做开发验证，在 Windows + CUDA 上做正式训练，并提前处理设备和路径差异。

系统排错

当 loss 不降、采样异常、路径错乱或 Pages 部署偏差时，你知道该先检查哪一层，而不是盲目改代码。
